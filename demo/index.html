연구실 추천(MVP #1 일부, #4)은 연구실별 논문 키워드 데이터 수집 파이프라인(로드맵 1개월차)이 아직 구축되지 않아 이 데모에는 포함하지 않았습니다. 자연어 설명 생성(축E)은 현재 규칙 기반 템플릿이며, 실제 서비스에서는 온톨로지 검증 그래프 기반 GraphRAG + 경량 로컬 LLM으로 교체될 예정입니다. 교과목 매칭 임베딩도 현재는 문자 n-gram 코사인 유사도이며, 로드맵 2~3개월차에 BGE-m3 파인튜닝 임베딩으로 교체해 정확도를 높일 계획입니다.
