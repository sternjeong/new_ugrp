# 3분커리 (3-min Curri)

연구참여·연구실 진학을 고민하는 포스텍 학생이 자신의 관심과 연결되는 연구실을 발견하고, 연구 주제와 준비 경로를 살펴보며 후보를 좁히도록 돕는 서비스입니다. ‘3분’은 빠르고 간편한 경험을 뜻하는 브랜드명입니다.

## 개발 기준

**[제품 기준 및 개발 방향](docs/product/PRODUCT_PLAN.md)**을 먼저 읽습니다. 제품의 목적, 합의된 MVP 범위, 사용자 흐름, 데이터 사용 원칙, 검증 시나리오와 후속 계획을 담고 있습니다. 화면·기능·코드 구조·데이터 계약은 [서비스 코드 분석](docs/analysis/SERVICE_CODEBASE_ANALYSIS.md)에 정리했습니다.

현재는 실제 데이터를 사용하는 로컬 MVP가 구현되어 있습니다. 추천은 사람이 검토하는 연구실·과목 프로필을 공유 개념으로 연결하는 규칙 기반이며, 연구 주제 가이드는 공개 자료 탐색·방법 비교·추가 준비를 위한 초기 제안입니다.

## 실행

Python 3.11 이상에서 저장소 루트에서 실행합니다. 추가 패키지나 API 키는 필요하지 않습니다.

```bash
python3 -m curri
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. Codespaces에서는 `--host 0.0.0.0`과 포트 전달을 사용할 수 있습니다. 로컬 DB는 `.local/curri.sqlite`에 생기며 Git에 포함하지 않습니다.

```bash
python3 -m unittest discover -s tests -v
```

[개발·실행 안내](docs/product/DEVELOPMENT.md)에 데이터 준비, 로컬 계정, 저장 위치, 테스트와 현재 추천 방식의 한계를 정리했습니다. 이 서버는 로컬 프로토타입 검증용입니다.

## MVP 흐름

관심·기본정보 입력 → 연관 연구실과 추천 이유 → 연구실 하나 선택 → 연관 과목과 연결 이유 → 수강 과목 선택 → 현재 시도할 연구와 추가 준비할 연구 가이드 → 저장·메모.

- 연구실은 한 번에 하나씩 상세 탐색하고, 최종적으로 후보 2~3곳을 좁힙니다.
- 첫 연구실 상세 탐색은 로그인 없이 전체 이용할 수 있고, 두 번째 다른 연구실부터 로그인합니다.
- MVP에는 과금과 독학·프로젝트 경험 입력을 포함하지 않습니다.
- 확장(2026-10-01, 더미 데이터로 시연): 회원가입 시 확장 프로필, 연구참여 후기 게시판·작성, 연구실 상세의 재학 중인 선배 정보와 웹 내 쪽지. 데모 계정 비밀번호와 범위는 [개발 안내](docs/product/DEVELOPMENT.md#커뮤니티-기능-2026-10-01-추가)를 참고하세요.
