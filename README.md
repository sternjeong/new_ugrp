# new_ugrp — 3분커리 MVP 데모

2026 POSTECH UGRP(기술창업트랙) "3분커리(3-min Curri)" 프로젝트의 **시제품 MVP 데모**입니다.
전체 설계 문서·연구 축(A/B/C/D/E)·원본 데이터셋은 [`sternjeong/UGRP_2026`](https://github.com/sternjeong/UGRP_2026) 저장소에 있습니다. 이 저장소는 그 설계를 실제로 동작하는 형태로 보여주는 데모만 담습니다.

## 데모 실행

```
open demo/index.html   # 또는 브라우저에서 파일을 직접 열기
```

빌드나 서버가 필요 없는 정적 페이지입니다. `demo/index.html`을 더블클릭하거나 정적 호스팅(GitHub Pages 등)에 올리면 바로 동작합니다.

## 기존 목업 데모와의 차이

`UGRP_2026/demo.html`은 두 개의 시나리오에 대한 결과가 전부 하드코딩된 **정적 UI 목업**입니다. 이 저장소의 데모는 한 단계 더 나아가, 실제 데이터에 대해 브라우저에서 즉석으로 계산합니다.

| 항목 | 실제 데이터 기반 여부 |
|---|---|
| 교과목 매칭 (관심사 → 과목) | ✅ 실제 419개 학부 교과목 코퍼스에 대한 문자 n-gram + 단어 TF-IDF 코사인 유사도를 입력마다 즉석 계산 |
| 선수과목 경로 (테크트리) | ✅ 실제 301건 `hasPrerequisite` 그래프를 매칭된 과목부터 역추적 |
| 후속 과목(unlocks) | ✅ 위 그래프의 역방향 인덱스 |
| 타과 융합 신호 | ✅ 실제 406건 `hasSynergyWith` 관계에서 학과가 다른 링크만 추출 |
| 자연어 설명 생성 | ⚠️ 위에서 실제로 계산된 값(과목명·코드·유사도·체인)을 채워 넣는 규칙 기반 템플릿 — LLM 호출 없음 |
| 연구실 추천 | ❌ 아직 미구현 — 연구실별 논문 키워드 데이터 수집 파이프라인(로드맵 1개월차)이 선행되어야 함 |

즉 축A(임베딩 매칭)와 축D(온톨로지/선수과목 그래프)는 "실제로 작동하는 축소판"이고, 축E(생성 설명)는 값은 실제이나 생성 방식은 아직 LLM이 아닌 템플릿이며, 연구실 축은 데이터가 없어 의도적으로 비워두었습니다. README §핵심 기능의 어떤 부분이 실제로 서 있고 어떤 부분이 남았는지 데모 하단 "아직 구현되지 않은 부분" 섹션에서 그대로 밝힙니다.

## 저장소 구성

| 경로 | 설명 |
|---|---|
| `demo/index.html` | 데모 페이지 (마크업 + 스타일) |
| `demo/app.js` | 검색/매칭 엔진, 선수과목 그래프 탐색, 렌더링 로직 |
| `demo/data.js` | `scripts/build_demo_data.py`로 생성된 실제 커리큘럼/선수과목/융합 데이터 스냅샷 |
| `scripts/build_demo_data.py` | `UGRP_2026` 저장소의 원본 jsonl에서 `demo/data.js`를 재생성하는 스크립트 |

## 데이터 갱신

`UGRP_2026` 저장소가 형제 디렉터리(`../UGRP_2026`)에 있다면:

```
python3 scripts/build_demo_data.py
```

다른 경로에 있다면 인자로 경로를 넘깁니다: `python3 scripts/build_demo_data.py /path/to/UGRP_2026`
