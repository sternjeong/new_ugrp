# 과목 세부 내용–연구 내용 연결: 탐색적 재분석

GPU 점수 계산 전에 고정. 과거 정제 전 자료의 독립 평가자 A/B가 기존에 평정한 28개 교수 행·327개 연구실–과목 쌍을 사용한다. 결과는 현 서비스의 307 연구실에 대한 검증이 아니다. 라벨은 쌍 전체의 준비 관련도(0,1,2)이며, 특정 논문–강의 문장 연결의 정확도 라벨이 아니다. 과거 여러 방식의 상위 5개 합집합만 판정된 후보 풀이다.

동일 연구실 근거(키워드와 대표 논문 청크)를 사용해 두 가지를 비교한다. A는 기존 연구실 청크와 과목의 제목+설명/제목+강의계획 두 청크 사이 최대 BGE-M3 코사인. B는 각 과목 본문을 문장·번호 경계에서 최대 12조각으로 나눠 각각 제목을 붙이고 최대 코사인. 점수 최대인 연구실 청크와 과목 조각을 B의 후보 근거로 저장한다. 256토큰, 동일 BGE-M3 revision `5617a9f61b028005a4858fdac845db406aefb181`, 정규화, GPU 계산. 서로 다른 과목별 후보 수가 달라 최대값 기회에 편향이 생길 수 있다.

각 평가자별 근거 부족 쌍을 제외하고 같은 연구실의 판정 후보만 대상으로 nDCG@5(관련도 0/1/2의 2^r-1 gain), P@5(관련도 2), 관련도 0 비율을 계산한다. 후보가 5 미만이거나 양성 판정이 없는 연구실은 제외하고 수를 보고한다. 동일 연구실 평가 후보만 비교하며 서로 다른 연구실의 절대 코사인은 비교하지 않는다. 연구실 공유근거 구성요소를 bootstrap 단위로 2,000회 재표본하여 짝차이 구간을 구한다. 평가자 결과는 합치지 않는다.

구체 근거의 충실도는 기존 라벨로 측정할 수 없으므로 사후에 표본을 원문과 함께 공개하고 별도 판정 전까지 정량 품질을 주장하지 않는다. 과거 라벨과 기존 실험 내용을 이미 확인했으므로 확인적 실험이 아닌 탐색적 재분석이다. 미판정 후보의 점수나 전체 과목에 대한 recall을 주장하지 않는다.
