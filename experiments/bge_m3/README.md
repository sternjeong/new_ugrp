# bge-m3 연구실 ↔ 교과목 매칭 실험

연구실 주제 문장과 과목 설명·강의계획 조각을 같은 다국어 임베딩 모델(BAAI/bge-m3)로 벡터화해, 연구실별 연관 과목을 찾는 실험이다. 앱에는 아직 반영하지 않았다.

## 파일

| 경로 | 내용 |
|---|---|
| `bge_m3_colab_v2.ipynb` | Colab(T4 GPU) 실험 노트북. 버전 A~E 계산, 자동 지표, 블라인드 채점 파일 생성 |
| `bge_m3_colab_v4.ipynb` | 재순위 모델(bge-reranker-v2-m3) 실험. H 후보 30개를 재정렬(R1), 규칙 가산 포함(R2), 재순위 점수 기준점 컷오프 |
| `bge_m3_colab_v3.ipynb` | 다음 실험. 허브 보정 완화·주제당 최소 1개·규칙 비중(E~H)과 컷오프(10개 고정 vs 기준 이상만) 비교. v2 채점을 재사용하고 새 쌍만 채점 |
| `results/rankings_v2.json` | 버전별·연구실별 상위 30개 과목과 근거 문장 쌍 |
| `results/metrics_v2.csv` | 정답 없이 계산한 자동 지표 |
| `results/settings_v2.json` | 실행 조절값 (λ=0.7, γ=0.03, β=0.04 등) |
| `judge/judge_packet.json` | 채점용 파일. 연구실 20곳, 416쌍. 버전 정보 없음 |
| `judge/judge_key.json` | 채점 id → 과목 대응표 (채점 후에만 사용) |
| `judge/judge_scores.json` | Claude Code의 0~2점 블라인드 채점 결과 |

입력 데이터는 저장소 `data/`의 `courses.jsonl`, `lab_profiles.jsonl`, `course_profiles.jsonl`, `concepts.json`이다.

## 버전

| 버전 | 내용 |
|---|---|
| A | v1 방식 (조각 쌍 상위 3개 평균) |
| B | A + 조각 정리 (짧은·무의미 줄 제거, 강의계획 3줄 묶음) |
| C | B + 허브 보정 (모든 연구실과 두루 가까운 과목 감점) |
| D | C + 주제 분산 + 교차개설 중복 제거 |
| E | D + 규칙 엔진 개념 일치 가산점 |

## 결과 요약 (2026-10-08)

자동 지표는 수정한 대로 좋아졌다.

| 지표 | A | B | C | D | E |
|---|---|---|---|---|---|
| 최대 허브 (한 과목이 상위 10개에 든 연구실 수) | 29/56 | 20/56 | 10/56 | 9/56 | 13/56 |
| 한 주제 독점 연구실 | 18 | 24 | 28 | 0 | 0 |
| 짧은 근거 비율 | 31% | 0% | 0% | 1% | 1% |
| 중복 | 28 | 33 | 32 | 0 | 0 |
| 은정답 재현율 | 0.56 | 0.52 | 0.51 | 0.48 | 0.73 |

관련도 채점(상위 10개, 연구실 20곳)은 거의 같았다.

| 버전 | 평균(0~2) | 2점 | 0점 | nDCG@10 |
|---|---|---|---|---|
| A | 0.88 | 27% | 40% | 0.86 |
| B | 0.89 | 28% | 40% | 0.85 |
| C | 0.82 | 27% | 45% | 0.83 |
| D | 0.76 | 24% | 48% | 0.79 |
| E | 0.87 | 28% | 40% | 0.84 |

- 허브 보정(C)과 주제 분산(D)은 목록을 고르게 만들었지만 관련도는 낮췄다. 규칙 가산점(E)이 이를 대부분 회복했다.
- 모든 버전에서 1~3위는 평균 1.0~1.55점이고 6위 이후는 0.4~0.7점이다. 순위 신호는 위쪽에서만 믿을 만하다.
- 모든 버전에서 상위 10개 중 약 40%가 무관하다. 관련 과목이 적은 연구실(안성수, 한해욱, 유환조)도 10개를 억지로 채우는 것이 원인이다.

채점은 Claude Code 한 명의 판단이며 사람 정답이 아니다. 버전 간 상대 비교로만 사용한다.

## v3 결과 요약 (2026-10-09, `V3/`)

v2 채점 359쌍을 재사용하고 새로 나온 36쌍만 추가 채점했다(`V3/judge_scores.json`, 395쌍).

| 버전 | 10개 평균 | 10개 0점 | 컷오프 개수 | 컷오프 평균 | 컷오프 0점 | 컷오프 회수율 |
|---|---|---|---|---|---|---|
| A | 0.88 | 40% | 4.7 | 1.17 | 27% | 31% |
| E | 0.87 | 40% | 3.9 | 1.15 | 29% | 25% |
| F | 0.95 | 36% | 3.7 | 1.27 | 20% | 27% |
| G | 1.05 | 28% | 3.9 | 1.37 | 18% | 29% |
| H | 1.05 | 28% | 4.0 | 1.34 | 19% | 29% |

- 규칙 가산점을 0.08로 올린 G·H가 처음으로 v1보다 확실히 좋아졌다(평균 0.88 → 1.05, 0점 40% → 28%).
- 허브 보정·주제 분산(G)과 아무 보정 없는 단순 하이브리드(H)의 관련도 차이는 거의 없다.
- 컷오프는 정확도를 크게 올리지만(0점 18%) 개수가 평균 4개로 줄어 관련 과목 회수율이 65% → 29%로 떨어진다.

## v4 결과 요약 (2026-10-09, `V4/`)

H 후보 30개를 재순위 모델(bge-reranker-v2-m3)로 다시 정렬했다. 새로 나온 73쌍만 추가 채점했다(`V4/judge_scores.json`).

| 버전 | 상위 3개 평균 / 0점 | 상위 5개 평균 / 0점 | 10개 평균 / 0점 |
|---|---|---|---|
| A | 1.25 / 22% | 1.12 / 27% | 0.88 / 40% |
| H | 1.43 / 13% | 1.23 / 23% | 1.05 / 28% |
| R1 (재순위만) | 1.50 / 7% | 1.30 / 15% | 1.00 / 30% |
| R2 (재순위 + 규칙) | 1.50 / 7% | 1.35 / 14% | 1.05 / 26% |

- 재순위는 상위 3~5개의 정확도를 가장 크게 올렸다. 10개 전체로는 H와 비슷하다.
- 재순위 점수는 대부분 매우 낮다(중앙값 0.002, 90%가 0.05 이하). 기준점 0.5를 넘는 과목이 드물어 컷오프가 사실상 "최소 3개"로 동작했다. 절대 기준점 대신 순위 기반으로 개수를 정해야 한다.
