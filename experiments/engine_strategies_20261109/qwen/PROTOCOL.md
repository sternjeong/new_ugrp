# 사전 계획: A5의 해석기를 Qwen2.5-7B로 교체 (2026-11-09)

상위 실험(`../PROTOCOL.md`)과 같은 질의 50개, 같은 검색 구성(사전 + 조각 임베딩 + 과목 연결, 가중치 그대로)에 해석기만 바꾼다.

- **AQ:** Qwen/Qwen2.5-7B-Instruct, Kaggle T4 GPU, 16비트, 샘플링 없음. Sonnet과 같은 지시문에 JSON 형식 지시만 더한다. 출력을 JSON으로 읽지 못하면 해석 실패로 기록하고 원문으로 검색한다(`intent=search`, 원문을 좋아함·검색문으로 사용).
- **판정:** 상위 실험에서 평가하지 않은 연구실이 AQ 상위 5에 나온 질의만, Sonnet 판정자 5명이 그 연구실과 이미 평가된 기준 연구실 6개(풀에서 높은·낮은 점수 고루)를 함께 평가한다. 추천·거절 판단은 상위 실험의 다수결을 그대로 쓴다.
- **보정 점검:** 기준 연구실의 새 점수와 예전 점수의 평균 차이와 상관을 보고한다. 차이가 크면 결과를 약한 증거로 본다.
- **지표:** 상위 실험과 같은 적합도, 추천 질의 nDCG@5. AQ−A5, AQ−A0, AQ−A4의 질의 단위 bootstrap 95% 구간. 호출당 시간과 해석 실패 수.
