# 사전 등록 — 결과를 보기 전에 고정한 판정 기준 (2026-10-11)

이 문서는 `run_gate.py`·`run_feedback.py`를 실행하기 전에 작성했고, 결과를 본 뒤 바꾸지 않는다. 바꿔야 하면 새 버전으로 새로 등록한다.

## 질문
1. 피드백과 무관한 "자격 관문(gate)"으로 무관한 과목을 걸러내면서 관련 과목은 얼마나 남길 수 있는가?
2. 사용자 피드백(연구실마다 "가장 맞음 1개 / 가장 안 맞음 1개")으로 순서를 조정할 때, 순위가 밀리며 무관한 과목이 목록에 들어오는 일을 어떻게 막는가?

## 데이터
- 후보: `bge_m3/V4/rankings_v4.json`의 R2 상위 30개 × 연구실 20곳(채점이 있는 곳).
- 정답 대용: Claude 0~2점 블라인드 채점 719쌍(기존 522 + 이번에 11~30위 197쌍 보강, `labels_all.json`). **사람 정답이 아니다.**

## 실험 1 — 관문 기준 (`run_gate.py`)
- 후보 규칙: 재순위 점수 하한(rr≥t), 순위 상한(rank≤k, 대조군), 공유 개념(주요 개념 ≥1), 조합(AND/OR).
- 선택 규칙(결과 보기 전 고정): 연구실 5-겹 교차검증. 학습 연구실에서 "무관(0점) 비율 ≤ 25%이고 목록이 3개 이상인 연구실 ≥ 90%"를 만족하는 규칙 중 관련(≥1점) 회수율이 최대인 것을 고르고, 검증 연구실에서 같은 지표를 보고한다. 만족하는 규칙이 없으면 무관 비율이 가장 낮은 규칙 중 길이 조건을 만족하는 것을 고른다.
- 보고 지표: 통과 목록의 0점 비율, 관련(≥1)·핵심(2점) 회수율, 목록 길이 분포(중앙값, 3개 미만 연구실 수, 0개 연구실 수).

## 실험 2 — 피드백 시뮬레이션 (`run_feedback.py`)
- 가짜 사용자: 화면에 보인 상위 10개(관문 방식은 통과 목록의 앞 10개)에서 라벨이 가장 높은 것을 "최고", 가장 낮은 것을 "최악"으로 고름(동점 무작위). 확률 p로 무작위 항목을 고르는 잡음, 비율 m은 최고·최악을 뒤바꾸는 악의 사용자.
- 보정: `이동 = clamp(A·(최고표−최악표)/(응답 수+k), −δ, +δ)` 순위만큼 이동(A=10).
- 방법: M0 반영 없음 / M1 순진(관문 없음, 항상 10개 채움) / M2 관문+가변 길이 / M3 M2+상한 δ / M4 M3+완충 k / M5 집합 고정(재정렬·제외만, 새 항목을 들이지 않음).
- 조건: 사용자 수 {5,10,20,40} × 잡음 {0,0.2,0.4} × 악의 비율 {0,0.1}, 연구실별 200회 반복 평균.
- 지표: nDCG@5, nDCG@10(정답 라벨은 R2 상위 30개 전체), 새로 들어온 항목 수와 그 0점 비율, 목록 길이, 0점 비율.

## 판정 기준 (모두 만족해야 "권고안 채택")
1. 관문을 쓰는 방식(M2~M5)에서 새로 들어온 항목은 모두 관문을 통과한 것이어야 한다(구조적 검사). M5는 새로 들어온 항목이 0건이어야 한다.
2. 관문 방식의 새로 들어온 항목 중 0점 비율이 M1(순진)보다 낮아야 한다.
3. 잡음 0.2·악의 0.0 조건에서 사용자 10명 이상이면 M3 또는 M4의 nDCG@5가 M0 이상이다(평균 차이 −0.01 이내 허용).
4. 잡음 0.4 또는 악의 0.1 조건에서도 M4의 nDCG@5가 M0보다 0.03 넘게 떨어지지 않는다.
5. 선택된 관문에서 목록이 3개 이상인 연구실이 90% 이상이다.

기준을 못 넘으면 "미채택"으로 보고하고 어떤 기준에서 실패했는지 적는다.
