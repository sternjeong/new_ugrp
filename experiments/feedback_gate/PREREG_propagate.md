# 사전 등록 3 — 신호 퍼뜨리기 (2026-10-11)

`run_propagate.py` 실행 전에 고정한다. 결과를 본 뒤 바꾸지 않는다. 앞선 [PREREG_explore.md](PREREG_explore.md) 실험에서 "탐색 칸은 연구실당 응답이 많이 필요하다"는 한계가 나왔고, 베타에서는 응답이 연구실에 흩어질 것이므로 **비슷한 연구실끼리 같은 과목의 "예/아니오" 응답을 부분적으로 공유**하면 적은 응답으로도 발견이 일어나는지 시험한다.

## 방법
- **응답 흐름:** 연구실 20곳 전체에 대해 사용자 조회 V번이 무작위 연구실에 하나씩 떨어진다(연구실당 평균 V/20번). 사용자는 그 연구실의 탐색 풀(9~20위 & 공유 개념 ≥ 1)에서 2칸을 보고 "도움이 되나요?"에 답한다. 정책은 UCB(유효 응답 기준).
- **연구실 유사도:** 두 연구실의 주요 개념 집합의 자카드 유사도 `sim`. `sim < 0.2`이면 0으로 본다.
- **유효 응답:** 연구실 L'의 과목 c에 대해 `유효 = L' 자체 응답 + Σ(다른 연구실 L의 같은 과목 c 응답 × sim(L,L'))`. L의 풀에 c가 있어야 L에서 응답이 생긴다.
- **승격/탈락 규칙:** 앞 실험과 같다(유효 응답 ≥ 6이고 윌슨 90% 하한 ≥ 0.5이면 승격, 유효 응답 ≥ 5이고 상한 < 0.4이면 탈락). 윌슨 계산에 소수 응답 수를 그대로 쓴다.
- **비교 방법:** N0 퍼뜨리기 없음(앞 실험과 같음) / N1 유사도 가중 / N1g N1 + 해당 연구실 자체 응답이 2개 이상 있어야 승격 / N2 유사도 무시하고 같은 과목이면 모든 연구실 응답을 weight 0.5로 합침(과전파 대조군).
- **응답 모델:** 앞 실험과 같다. 라벨별 "예" 확률 (핵심, 부분, 무관) = 선명 (0.9, 0.5, 0.1) / 보통 (0.75, 0.5, 0.25) / 흐림 (0.65, 0.5, 0.35). 잡음 0.2, 악의 0. 판정은 선명·보통에서 하고 흐림은 참고로만 보고한다.
- **규모:** 전체 조회 수 V ∈ {40, 100, 200, 400, 800} (연구실당 평균 2, 5, 10, 20, 40번). 100회 반복 평균. 연구실 56곳 전체에서는 같은 V가 연구실당 약 0.36배로 줄어든다.
- 데이터 설명: 같은 과목이 여러 연구실 풀에 나오는 정도와 "한 연구실의 핵심 과목이 비슷한 연구실에서도 관련 있는 비율"(전이 충실도)을 함께 보고한다.

## 지표
승격 건수, 승격된 과목 중 0점 비율, 풀의 핵심(2점) 중 발견 비율, 자기 연구실 응답이 없이 다른 연구실 응답만으로 승격된 건수와 그 0점 비율, 무관 과목 노출 비율, 최종 목록 0점 비율과 핵심 과목 수.

## 판정 기준 (모두 만족해야 "채택")
1. **효과:** V = 200, 선명·보통에서 N1g의 풀 핵심 발견율이 N0보다 15%p 이상 높다.
2. **정확도:** V ≥ 200, 선명·보통에서 N1g의 승격 중 0점 비율 ≤ 15%.
3. **유사도 가중의 가치:** V = 400, 선명·보통에서 N1g의 승격 중 0점 비율이 N2 이하다.
4. **순수 전이의 안전:** V = 400, 선명·보통에서 N1의 "자기 응답 없이 승격된" 과목 중 0점 비율 ≤ 20% (N1g는 이 승격을 막는 변형이므로 N1에서 측정).
5. **적은 응답에서의 효과:** V = 100, 선명에서 N1g의 풀 핵심 발견율 ≥ 25%.

기준을 못 넘으면 "미채택"으로 기록하고 어느 기준에서 실패했는지 적는다.
