# 임베딩 입력 필드 제거·추가 실험 사전등록

2026-10-16. GPU 순위와 새 판정 패킷을 만들기 전에 고정한다. `final_courses.jsonl`·`final_labs.jsonl`은 수정하지 않는다. 이번 질문은 **교수별 연구실↔준비 과목 검색**에서 연구 내용 외 필드가 상위 노출 품질을 해치는가이다. 연구실 발견 질의와 실제 학생 선택의 성능은 별도 질문이다.

## 근거와 가설

- [BEIR 원 논문](https://arxiv.org/abs/2104.08663)은 검색기 비교에 다양한 도메인·동일 평가 틀을 사용한다. 공개 벤치마크의 점수를 본 서비스로 이전하지 않고, 같은 후보·라벨·지표를 쓰는 방식만 참고한다.
- [BGE-M3 원 논문](https://arxiv.org/abs/2402.03216)은 다국어·다중 세분도 검색을 다룬다. 긴 입력을 지원한다는 사실만으로 크롤링 전체가 유익하다는 뜻은 아니다.
- [Multi-view Content-aware Indexing 원 논문](https://arxiv.org/abs/2404.15103)은 고정 길이 청크에 무관한 내용이 섞일 수 있음을 분석한다. 여기서는 필드 단위 제거·추가로 같은 우려를 실측한다.

### 입력과 방법

기존 `complete_subset_v1.json`의 941과목 전체를 공통 후보로 두고, `rich_split_v1.json`의 **보류 137공유근거 구성요소·180교수 행 전부**를 GPU 순위 대상으로 쓴다. 앞선 평가에 쓰인 112구성요소·136교수 행은 탐색 집합이다. 당시 추출에서 남긴 25구성요소·44교수 행 중에도 **7구성요소·16교수 행은 `previous_split=test`**로 과거 시험에 노출됐다. 따라서 `previous_split=unused`인 **18구성요소·28교수 행만 새 확인 집합**으로 고정하고 나머지 7도 탐색으로 둔다. 이는 `rich_split_v1.json`의 기존 메타데이터와 선택 ID만으로 GPU 순위 전 확인했다. 18개는 이전 미사용 보류 106구성요소의 부분 표본으로, 단일 이항 비율의 최악 경우 95% 오차폭도 유한모집단 보정 약 ±21%p다. 짝차이의 검정력은 더 약하므로 효과 미입증은 무효과가 아니다. 성능 불확실성 단위는 교수 행이 아니라 공유근거 구성요소다. 모든 방법은 같은 BAAI/bge-m3 개정 `5617a9f61b028005a4858fdac845db406aefb181`, SentenceTransformer `encode` dense 출력·정규화 임베딩, 256토큰 상한, 청크 간 최대 cosine, 과목 ID 동률 정렬을 사용한다. 실행 설정과 pooling API를 노트북·manifest 해시에 묶는다. 인코딩·행렬 연산은 **Kaggle GPU에서만** 실행한다. 로컬에서는 JSON 정리와 통계만 계산한다.

기본 비교는 `core`, `core+lab_admin`, `core+course_admin`, `core+both_admin`의 2×2이다. **유일한 확인적 대비는 `core−core+both_admin`**이고 나머지는 원인 분해용 탐색 비교다. `core+learning_context`는 추가 탐색 비교다. `research_intro` 발췌는 별도의 개인정보·분류 감사를 통과하기 전까지 이번 GPU 순위에 넣지 않는다. 어떤 필드도 단순 문자열 길이 때문에 제외하지 않는다. 빈 필드는 빈 청크를 만들지 않는다. 강의목표가 설명과 복사된 경우 이중 인코딩하지 않는다. 후보가 같은 내용으로 교차 개설됐더라도 원본 코드를 자동 합치지 않고, 동일 내용 중복 노출을 별도 보고한다.

**직렬화 고정:** 각 텍스트 값에서 이메일 주소와 `0XX-XXXX-XXXX`류 전화번호를 제거한 뒤 연속 공백을 단일 공백으로 접고 앞뒤 공백을 제거한다. 원본 순서를 유지한다. `keywords`는 배열 순서대로 `키워드: ` 뒤에 `; `로 결합한 청크 하나다. 각 대표 논문은 `논문: {title} | {abstract[:400]}` 형태의 청크 하나이며 초록 최대 400 **문자**는 정규화 후 자른다. 과목은 `과목: {course_title} | 설명: {description[:1000]}`와 `과목: {course_title} | 진도: {Lecture progress plan[:1000]}`를 각각 만들고, 본문 최대 1,000 **문자**는 정규화 후 자른다. 위 추가 메타데이터는 열거한 필드 순서대로 `필드명: 값`을 ` | `로 잇고 최대 1,000문자의 청크 하나로 만든다. 배열은 원본 순서로 `; ` 결합한다. JSON 객체 전체나 URL·이메일·전화·구조화된 사람 이름은 직렬화하지 않는다. 자유 서술 중의 사람 이름을 완전히 식별할 수 있다는 보장은 없다. 빈 값은 해당 조각에서 생략하고, 빈 청크는 만들지 않는다. 청크 겹침은 없다. 모델의 256토큰 절단은 마지막에 동일하게 적용한다. 각 변형의 필드별 청크 수·문자 수·모델 토큰 길이 분포를 보고한다.

`has_lab_site`는 불리언 `true`/`false`를 소문자 문자열로 기록하며 `false`도 보존한다. null·빈 문자열·빈 배열은 해당 필드를 생략한다. 셔플 보조 분석은 연구실과 과목을 **각각** 분리해, 메타데이터 청크가 비어 있지 않은 엔터티 행 사이에서 청크 전체를 해시 순열로 교환한다. 원본 메타데이터 청크가 비어 있는 행은 그대로 빈 상태를 유지한다.

`lab_mates`, 교수·학생 이름, 이메일, 연락처, 오피스 위치, `admission`, `course_operation`, `other_info`는 이번 인코딩 입력과 심사 패킷에서 제외한다. 이 필드에 관한 직접적인 성능 결론은 내리지 않는다. 원본 연구실 소개에 혼입된 인물·위치·뉴스의 양은 로컬 감사에서 별도로 보고하며, 개인 식별 문구를 회의 자료에 복제하지 않는다. 학과·센터를 가진 행과 없는 행의 결과 차이는 기술적으로만 확인하고 모집단 일반화하지 않는다.

### 판정과 성공 기준

**새 확인 18구성요소·28교수 행**에서 각 변형의 상위 5개 **합집합**을 method/rank-blind 패킷으로 만든다. 모든 쌍은 두 Luna가 각각 새로 관련도 0/1/2와 근거부족 flag를 판정하며, 과거 라벨을 섞지 않는다. 패킷에는 모든 변형에 동일한 연구 내용 창(프로필의 연구실 `core` 청크, 과목 `core` 청크)만 제공한다. 이 창은 기준 검색법과 입력이 겹치므로 확인 결과는 **그 연구 근거 창으로 판정 가능한 준비 과목**의 품질로 제한한다. 운영 메타데이터가 실제로 담은 추가 연구 신호까지 판정했다고 주장하지 않는다. 패킷 작성자는 방법 대응표를 라벨 완결 전 심사위원에게 제공하지 않는다. 두 심사위원은 과거 실험에서 일부 원문을 본 적이 있고, 특히 B의 이전 노출 원문 ID 전부를 복구할 수 없으므로 새 집합도 **평가자에게 완전 블라인드라고 주장하지 않는다**. 과거 쌍 라벨을 쓰지 않는 새 판정집합이라는 제한된 독립성만 주장한다.

기존 112구성요소와 과거 시험 7구성요소의 순위 이동·청크 수·중복 노출은 탐색적 구조 지표로만 보고한다. 이전 라벨과 새로운 `core` 판정 창의 동일성을 보장할 수 없으므로 **이번 실험의 품질 지표에 기존 라벨을 재사용하지 않는다**. 이 결정은 새 순위와 판정 전에 개인정보가 든 과거 패킷을 감사하며 정했다.

주지표는 구성요소 내 교수 행 평균을 먼저 구한 고정 5칸 효용 `sum(relevance)/10`; 부지표는 0점 비율, 행당 0점 하나 이상, 정확히 같은 제목·교육본문의 추가 점유 슬롯이다. 근거부족 쌍을 포함한 구성요소는 해당 방법의 점수에서 제외하고, 짝 비교는 양 방법 모두 완전한 구성요소만 사용한다. 각 Luna별 구성요소 재표본 5,000회 백분위 95% 구간을 제시한다. **새 18구성요소 확인 집합에서 두 Luna 모두** 유일한 확인적 대비인 주지표 차이(`core−core+both_admin`)의 95% 구간 하한이 +0.02를 초과할 때만 운영 메타데이터 제거의 실질적인 품질 이익을 인정한다. 그렇지 않으면 해악이 입증되지 않았다고 판정한다. 평가자 결과는 합치지 않는다. 기존 112구성요소와 이전 시험 노출 7구성요소의 결과·나머지 대비는 탐색적이며 구간을 함께 공개하되 확인적 채택 근거로 쓰지 않는다. 새 집합의 낮은 검정력 때문에 효과 미입증을 무효과 증거로 읽지 않는다.

추가 청크가 `max cosine`의 최대값을 올릴 기회가 늘어난다는 점을 별도 기전으로 보고한다. 청크 수·토큰 수 분포와 코어 대비 증가량을 조건별로 공개하고, 메타데이터 텍스트를 동일하게 비어 있지 않은 다른 엔터티에 결정적 해시 순열로 바꿔 붙인 `shuffled_admin`의 순위 안정성과 점수 변화를 보조 분석한다. 실제 메타데이터와 셔플 메타데이터의 차이는 내용 신호와 청크 기회 효과의 단서일 뿐 인과 분해의 증명은 아니다.

라벨 합집합은 각 방법의 상위 5개 노출만 포괄하므로 941과목 전체 회수율은 주장하지 않는다. 선행 연구의 외부 점수나 2026-10-15 기존 평가 점수를 새 변형의 성능으로 대체하지 않는다. 품질 개선이 있더라도 학생 선택, 연구실 현재 역량, 논문 대표성까지 입증한 것으로 보지 않는다.
