# Kaggle BGE 상위 5개 사후 확장 분석 계획

작성일 2026-10-15. BGE 상위 1개 결과와 질의 실험 결과를 이미 본 뒤 만든 **사후 확장**이다. 확증 실험으로 부르지 않는다. GPU 추론을 재실행하지 않고 Kaggle T4 완료 순위 `results/bge_rich_v1/rankings.json`(SHA-256 `0f6de4d99856ec5a74061b1edae7b793ef012eab823e48f6cdfba5659ab77434`)을 사용한다. 로컬 CPU에서 GPU 특화 모델 추론을 하지 않는다.

대상은 기존 보류 적격 112공유 근거 구성요소/136교수 행이며 과목 후보는 공통 941개다. `dense`와 `dense_plus_frozen_rule` 각각 상위 5개 합집합을 평가한다. 기존 관계 910쌍 및 BGE 상위 1개 추가 144쌍의 두 Luna 라벨은 동일 연구실·과목 쌍에 재사용한다. 그 밖의 고유 쌍만 새 방법·순위 블라인드 패킷으로 두 Luna가 독립 채점한다. 기존 관계 판정과 같은 원문 창 및 0/1/2 준비 과목 척도, 근거 부족 표시를 사용한다.

주 지표는 각 연구실의 상위 5칸 관련도 합/10, 무관(0점) 과목 비율, 무관 항목이 하나라도 있는 행 비율이다. 모든 방법이 5개를 반환하므로 분모는 고정 5칸이다. 근거 부족 항목이 하나라도 있는 행은 해당 심사위원의 품질 지표에서 결측으로 두고 수를 공개한다. 같은 행의 두 방법이 모두 평가 가능한 구성요소에서만 짝차이를 계산하고, 공유 근거 구성요소별 평균을 동일 가중한 95% bootstrap 구간을 제시한다. 심사위원별 원점수·결과를 섞지 않는다. 반환율과 중복 코드/동일내용 후보 점유는 별도 구조 지표로 낸다.

판정의 대상은 상위 5개 노출 품질이며 941개 전체 관련 과목의 회수율이나 이상적인 전체 nDCG가 아니다. 0.08 가산은 상위 1개 분석 전에 고정됐지만 이 상위 5개 확대 자체는 결과 후 결정했다. 두 Luna의 데이터 판정과 결과 검토를 모두 받아도 탐색적 조건부 결론만 기록한다. 기존 `bge_m3`의 재순위 모델·컷오프·자유 생성 이유는 이 확장으로 검증하지 않는다.
