# 최종 정보량 충족 집합의 임베딩 재실험: 상위 1개 검증 계획

실행 환경 수정(2026-10-14, 순위 결과 생성 전): GPU 전용 연산은 Kaggle T4에서 `bge_rich_kaggle.ipynb`로 실행한다. 로컬 `run_bge_rich.py`의 CPU 시도는 5/118 과목 배치에서 중단되어 순위나 평가 결과를 만들지 않았다. 사용자 지시에 따라 GPU 특화 연산을 CPU에서 재시도하지 않는다. Kaggle 실행 ID `20261014-234632-bge-rich-kaggle`과 패키지·장치 버전은 결과 manifest에 남긴다.

작성일 2026-10-14. 원래 `experiments/bge_m3` 실험의 과목 419개·연구실 56곳에서 얻은 상위 3~5개·컷오프 결론을 새 데이터에 자동 적용하지 않는다. 이 파일은 아직 임베딩 결과의 의미 라벨을 보기 전의 **축소된 재실험**이다.

## 공통 모집단과 방법

`complete_subset_v1.json`의 과목 941개 전부를 후보로, `holdout_relevance_v1/packet.json`에 고정된 보류 112구성요소·136교수 행을 질의로 사용한다. 후보 우주는 두 방법에서 같고, 소스 해시·원문 범위·스크립트 해시를 manifest에 남긴다. 기존 노트북의 연구실 `topic profile`이 최종 JSONL에는 그대로 없으므로 소개 앞 1,200자와 첫 5개 대표 논문 제목·초록 앞 400자를 연구실 근거로, 과목 제목·설명 앞 1,000자·진도 앞 1,000자를 과목 근거로 쓰는 **새 입력 적응**이다. 목표 필드는 설명과 동일한 행이 많아 반복하지 않는다.

`run_bge_rich.py`의 `BAAI/bge-m3` 정규화 임베딩 최대 유사도 순위와, 같은 점수에 동결 v15의 직접 방법·도구 연결이 있으면 0.08을 더한 순위를 비교한다. 이 보너스는 사전 고정값이며 결과를 보고 조정하지 않는다. `run_tfidf_rich.py`의 문자 n-gram TF-IDF 순위는 모델 다운로드 실패 때도 실행 가능한 탐색적 어휘 기준선이다. 기존 노트북의 허브 보정·다양성·재순위 모델은 이 축소 실험에 포함하지 않았으므로 그 결론을 재검증했다고 말하지 않는다.

재현 시 모델 리비전은 `5617a9f61b028005a4858fdac845db406aefb181`, 최대 토큰 길이는 256, 배치 크기는 16이다. 각 과목은 `제목 | 설명 앞 1,000자`, `제목 | 진도 앞 1,000자`의 비지 않은 최대 두 청크이며, 연구실은 소개 앞 1,200자와 첫 다섯 대표 논문의 `제목 | 초록 앞 400자` 중 비지 않은 청크다. 각 청크 임베딩을 L2 정규화하고 연구실 청크와 과목 청크의 내적 최대값을 그 쌍의 점수로 삼는다. 직접 규칙 연결이 있는 과목에만 유사도에 0.08을 더한다. 두 점수를 각각 소수 여섯 자리로 반올림하고, 동점은 대문자 정규화 과목 코드의 사전순으로 정렬한다. 소스와 스크립트 해시는 결과 manifest에 고정한다.

## 평가 범위

256토큰을 넘는 청크는 해당 리비전 tokenizer의 오른쪽 절단(`truncation=True`, `max_length=256`)으로 처리한다. 이는 `SentenceTransformer.encode`에 설정한 `max_seq_length=256`의 동작이며, tokenizer 버전은 결과 환경 기록에 남긴다.

동일 BGE 임베딩의 기본 순위와 고정 규칙 보너스 순위에서 **상위 1개** 연구실-과목 쌍을 추출한다. 기존 `holdout_relevance_v1` 패킷에 있는 쌍은 두 Luna의 완료된 라벨을 재사용한다. 새 쌍만 방법 이름·순위를 숨긴 별도 원문 패킷으로 두 심사위원이 독립 판정한다. 원래 패킷이 미완료인 동안 임베딩 품질을 결론짓지 않는다. 주 지표는 구성요소 내 교수 행을 먼저 평균한 상위 1개 0점 비율과 0/1/2 효용이며, 두 심사위원별 짝지은 구성요소 bootstrap 95% 구간을 보고한다. 적격 자료만으로 한 조건부 결론이며 사전 라벨을 보는 연구실과의 민감도를 함께 보고한다.

상위 1개 결과로 상위 3~5개 품질·컷오프 회수율·재순위 모델의 기존 결론이 맞았다고 선언하지 않는다. 두 Luna가 설계와 결과를 각각 검토해야 상위 1개 비교도 수용한다. 연구실·과목의 원문 창 크기가 규칙 평가보다 작으므로 방법 차이에 그 입력 차이도 포함된다.
