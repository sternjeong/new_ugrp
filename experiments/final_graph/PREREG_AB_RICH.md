# 최종 적격 자료의 설명 표시 방식 A/B 제한 파일럿

작성일 2026-10-15. 옛 `ab_test`의 여러 과목 목록·학생 페르소나 만족도는 옛 데이터와 단일 모델의 가상 페르소나에 의존했다. 이번 파일럿은 최종 적격 자료의 **동일 연구실·과목 27쌍에서 짧은 개념 문장과 원문 인용 문장 중 어느 쪽이 과목 선택 근거를 더 이해하기 쉬운지**만 두 Luna가 쌍별로 판정한다. 두 방식은 `reason_rich_v2`의 R0/R1로 이미 생성·심사된 문장이다. 새 순위나 새 모델 추론은 없다.

27쌍은 두 관계 판정자가 관련 있고 근거 충분하다고 본 B1 상위 1개이며, 따라서 대표성이 약하다. 두 Luna는 앞선 이유 문장 실험에서 같은 문장을 이미 보았고 형식으로 R0/R1을 추측할 수 있다. 좌우 위치와 방법명만 가린다. 이 파일럿은 실제 학생의 납득도, 여러 과목 목록의 선호, 클릭·선택 행동을 측정하지 않는다.

`reason_rich_v2/packet.json`의 같은 `pair_id`를 묶고 `sha256('ab-rich-v2|' + pair_id)` 첫 바이트 짝/홀로 좌우를 고정한다. 쌍별로 연구실·과목 원문 근거와 두 문장을 같이 보여 준다. 심사위원은 `left`, `right`, `tie`, `neither` 중 과목 선택을 이해하는 데 더 도움이 되는 문장을 고르고, 근거 없는 사실 주장이 있으면 별도 표시한다. `tie`는 둘 다 비슷하게 도움, `neither`는 둘 다 도움 안 됨이다. 좌우 키는 두 심사 파일이 완성될 때까지 공개하지 않는다.

주 지표는 27쌍에서 R1/R0/tie/neither 선택 수와 두 심사위원의 정확 일치율이다. 형식별 선호가 두 심사위원 모두에서 같은 방향이고 근거 없는 주장 표시가 늘지 않아야만 **이 제한 파일럿 내 표시 방식 선호**를 말한다. 불일치하면 우열 미정이다. 작은 조건부 표본에 모집단 추론 신뢰구간은 붙이지 않는다. 두 Luna의 결과 감사가 끝나야 기술 결론을 기록한다.

최초 `ab_rich_v1/packet.json`은 과목 원문이 제목 수준인 카드가 많아 근거 사실성 판정이 불균형하다는 사전 심사 B의 지적으로 라벨 전에 폐기했다. 사용 패킷 `ab_rich_v2/packet.json`은 동일한 연구실·과목 쌍의 `holdout_relevance_v1/packet.json` 원문 연구실·과목 창을 좌우에 공통으로 제공한다. 생성에 사용된 짧은 인용 span도 보존하되 두 문장의 사실성은 공통 전체 창에서 검토한다. 좌우 순서는 `sha256('ab-rich-v2|' + pair_id)`로 고정한다.
