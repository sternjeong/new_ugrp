## 검증할 가설

1. 같은 개념 어휘와 입력 필드를 썼을 때, 출처·문단·관계 유형을 가진 그래프 규칙은 단순 개념 교집합보다 `lab→course` 추천의 무관 과목 비율을 줄인다.
2. 단순 개념 교집합은 내용이 없는 과목·메뉴 혼입·논문 제목만의 언급에서 거짓 연결을 만든다. `teaches`와 `uses`의 직접 근거 및 학습 수준 구분이 이 오류를 줄인다.
3. 엄격한 규칙은 관련 과목 회수율을 낮출 수 있다. 관련 근거가 없을 때는 추천 개수를 채우지 않고 보류하는 것이 허위 연결보다 낫다.

## 개념·관계 스키마

개념은 `domain`, `problem`, `method`, `tool`, `material`, `knowledge` 유형 중 하나를 기본 유형으로 갖고, `aliases`, `broader/narrower`, `ambiguous_aliases`, `review_status`를 기록한다. 기존 70개 어휘는 후보 어휘로만 사용한다. 최종 데이터에서 누락된 수학·물리·화학·생명과학 등의 지식 개념은 검토 후 추가한다. `method`와 `knowledge` 사이 `requires_knowledge` 변은 외부 학문 상식으로 자동 생성하지 않는다. 명시적인 선수 지식 자료 또는 사람 검토가 필요하다.

| 변 | 생성 조건 | 금지할 도약 |
|---|---|---|
| `lab studies problem/domain` | 연구 소개의 실제 연구 문장 또는 연구실 연결이 확인된 논문 초록에 문제·대상이 명시됨 | 소속 학과·센터·메뉴·뉴스만으로 추정 |
| `lab uses method/tool` | 같은 근거 단위에서 방법을 실제 사용한다는 동사·맥락이 확인됨 | 단어 등장만으로 사용 주장 |
| `course teaches concept` | 제목, 설명, 목표, 진도에 학습·연습 대상으로 나타남; `coverage`와 `depth` 기록 | 참고자료·선수사항에만 나온 개념을 가르친다고 주장 |
| `lab_course supports_method` | 검토된 `lab uses method`와 `course teaches method`의 교집합, 양쪽 근거 ID 유지 | 동일 교수·학과·코드 접두부를 내용 근거로 사용 |
| `lab_course supports_foundation` | 위 방법과 검토된 `requires_knowledge`, `course teaches knowledge` 경로 | 지식 요구 관계를 LLM 추측만으로 확정 |

문단의 긍정/부정/향후 계획/교육 소개를 구분한다. `site_papers`와 `professor_papers`는 논문 수록 근거, `representative_papers`는 선정 근거이지만 연구실의 현재 방향으로 자동 승격하지 않는다. 논문 제목만 있을 때는 `title_only`로 표시하고 주제 후보까지만 허용한다. 같은 문서에 도메인과 방법이 각각 흩어져 있으면 둘을 결합한 프로젝트를 만들지 않는다. 양쪽 근거는 원문 문자열과 위치로 추적되어야 한다.

- 주 비교의 공통 원문 필드는 연구실 `research_intro`와 `representative_papers` 제목·초록, 과목 `course_title`·`description`·`Lesson Objectives`·`Lecture progress plan`이다. 메뉴·뉴스 제외 등 전처리는 동일한 소스에서 B0/B1 모두에 적용한다. `keywords`, 선수사항, 사이트·교수 논문 목록은 주 비교의 후보 근거에서 제외한다. 사이트·교수 논문을 추가하는 출처 확장 ablation은 현재 분할에서 공유 제목이 개발·시험 양쪽에 존재하므로 **탐색 결과로만** 보고하고 채택 기준에 포함하지 않는다. 확증 실험으로 삼으려면 해당 논문 목록까지 그룹화해 분할을 다시 고정해야 한다. 모든 방식은 같은 365개 임시 연구실 행과 1,316개 과목 행을 후보 모집단으로 사용한다. 공동 연구실 병합 결정이 끝나면 모두 같은 정규 ID로 다시 평가한다.

## 평가 표본과 블라인드 판정

난수 시드는 `20261014`로 고정한다. **분할 단위는 교수 행이 아니라 공유 근거 구성요소**다. 동일한 비결측 `lab_group`, 정규화 URL, 정규화 후 동일한 비결측 `research_intro`, 또는 같은 대표 논문의 DOI/OpenAlex ID/정규화 제목을 가진 행을 union-find로 묶는다. 이는 개발·시험 분할만 위한 그룹이며 **서로 다른 연구실의 엔터티를 병합하지 않는다**. 공유 논문 한 편도 동일 원문 근거가 개발과 시험에 동시에 들어가는 일을 막기 위해 분할 그룹에서는 연결한다. 구성요소가 개발·시험 경계를 넘지 않도록 한다.

URL은 `lab_url`과 `urls[].url`, `lab_group`에서 수집한다. 정규화는 `https://`가 없으면 붙여 파싱한 뒤 호스트를 소문자화하고 선두 `www.` 및 기본 포트 `:80`/`:443`을 제거한다. 경로의 대소문자는 유지하고 연속 `/`을 하나로 줄인 뒤 끝 `/`만 제거한다. 쿼리 매개변수는 정렬하여 유지하고 fragment는 제거한다. 소개문은 Unicode NFC, `\r\n`→`\n`, 연속 공백을 한 칸으로 만든 뒤 앞뒤 공백을 제거한다. 대표 논문 제목도 NFC·연속 공백 정규화와 `casefold()`만 적용하며 구두점 제거 같은 유사도 병합은 하지 않는다. 각 구성요소의 학과는 구성원 교수의 `department` 우선, 없으면 `departments` 첫 값으로 정하고, 여러 값이면 최빈값·동률은 사전순으로 고정한다. 다중 학과는 원본 목록을 유지하되 분할 층은 이 단일값을 쓴다.

구성요소를 학과별로 나누고 시드로 섞는다. 시험 60개 **구성요소**를 먼저 뽑는다: 학과별 가능한 최소 2개씩 할당하고, 남은 수는 학과의 구성요소 수에 비례한 최대잔여법으로 할당하며, 한 학과의 가용 수를 넘으면 나머지를 재배분한다. 이후 남은 구성요소에서 개발 30개를 학과별 가능한 최소 1개, 나머지 같은 방식으로 뽑는다. 구성요소의 모든 교수 행을 같은 split에 넣으므로 행 수는 60/30과 다를 수 있다. 연구실 소개 유무·대표 논문 초록 유무·기존 어휘 명중은 **사후 층별 진단**으로 보고하고 층화 표본이라고 부르지 않는다. 이 benchmark를 모집단 성능으로 외삽하거나 포함 확률을 임의 추정하지 않는다. 어휘 확장과 규칙 작성에는 개발 split만 쓰고, 분할 후 시험 split의 개별 텍스트를 규칙·어휘 고정 전 읽지 않는다. 이전 구조 감사 중 일부 연구실과 과목의 원문을 살펴봤으므로 시험셋을 완전한 미열람 자료라고 주장하지 않고 확인 가능한 prior-seen ID를 기록한다. 표본 ID, 설정, 코드 해시와 블라인드 키를 판정 전에 저장한다.

각 시험 연구실의 판정 풀은 B0-old/B0-expanded/B1/B2 각각 상위 20개와 동일한 고정 시드의 무작위 과목 10개를 합집합으로 만든다. 후보 관련도 패킷의 텍스트는 **쌍·방법·매칭 개념과 무관하게 행 자체에서 미리 추출**한다. 연구실은 소개의 처음 6,000자와 마지막 2,000자(겹치면 중복 제거), `representative_papers` 원본 순서 첫 5건의 제목 전체와 초록 첫 800자씩이다. 과목은 제목 전체, 설명 첫 2,000자, 목표 첫 2,000자, 진도 첫 4,000자다. 절단 사실과 원본 위치를 표시하고 부족한 패킷은 “정보 부족”으로 따로 표기한다. B1이 선택한 그래프 변이나 점수는 **후보 관련도 판정 패킷에 넣지 않는다**. 설명의 근거 충실도는 후보 관련도 판정이 끝난 뒤 방법별 출력과 출처를 별도 블라인드 패킷으로 평가한다. 근거가 없는 출력도 포함해 충실도 0점 후보로 판정한다. 동일 연구실-과목 쌍이 여러 방식에 나온 경우 관련도 라벨을 공유한다.

관련도는 0(연구실 문제/방법과 과목 학습내용 사이 설명 가능한 도움 없음; 같은 학과·교수·일반 단어만 겹침), 1(기초 이해나 한 측면의 준비에 도움; 해당 연구의 직접 방법을 가르치지는 않음), 2(연구실이 실제 사용하는 구체 방법·도구 또는 그 수행에 직접 필요한 검토된 지식을 과목이 가르침)으로 판정한다. 단순 주제 언급만으로 1점을 주지 않는다. 근거 충실도는 0(근거 없음/왜곡), 1(출처에 있음, 연결은 명시되지 않은 추론), 2(양쪽 근거와 관계가 명확)으로 별도 판정한다. 학생의 실제 숙련도·연구 수행 가능성은 이 라벨에 포함하지 않는다.

심사위원은 각각 `gpt-6-luna`를 분리된 세션에서 동일한 고정 프롬프트·패킷으로 사용한다. 두 판정의 가중 Cohen κ와 완전 일치율을 관련도·충실도별로 공개한다. 불일치를 임의로 평균하거나 제외하지 않고 각 심사위원 기준의 지표를 별도로 계산한다. 사람 전공자에게는 결과를 보기 전에 난수로 고정한 판정 풀 10%와 모든 심사위원 불일치 표본의 검토를 요청한다. 사람이 검토되지 않으면 실험 결과는 **Luna 기반 잠정 판정**으로만 보고한다.

주 지표는 상위 5개 0점 비율과 nDCG@5, **판정 풀 내 관련 회수율**(분모: 해당 연구실의 합집합 판정 풀에서 관련도 ≥1인 쌍 수), 목록 길이, 보류율이다. 상위 5개 0점 비율의 기본 집계는 반환된 최대 5개 항목 중 0점 항목 수를 반환 항목 수로 나눈 **항목 가중 비율**이며, 비어 있는 연구실은 분모에서 제외하고 별도 보류율에 포함한다. 연구실별 비율 평균도 함께 보고한다. nDCG@5는 합집합 판정 풀에서 가능한 이상적 상위 5개를 IDCG로 하고, 빈 목록은 0으로 둔다; 관련 후보가 풀에 0개면 nDCG는 정의되지 않아 별도 집계한다. 판정 풀 회수율도 분모 0인 연구실은 별도 집계한다. 이 회수율은 전체 1,316과목 중 관련 과목 회수율이 아니다. 무작위 음성 10개도 전체 관련 과목 수를 충분히 추정하지 못한다. 주 추론 단위는 **공유 근거 구성요소**다. 각 구성요소 안의 교수 행 지표를 먼저 평균한 뒤 60개 구성요소를 동일 가중하여 B1−B0-expanded 차이와 paired bootstrap 95% 신뢰구간을 계산한다. 교수 행을 동일 가중한 보조 결과도 별도 보고하지만, 그것으로 주 채택 판정을 내리지 않는다.

## 채택 기준과 반증

B1이 B0-expanded보다 상위 5개 0점 비율을 절대 10%p 이상 낮추고, **판정 풀 내** 관련 회수율 손실이 15%p를 넘지 않으며, 근거 충실도 0점 비율이 5% 이하일 때만 잠정 채택한다. 두 Luna 심사위원 각각에서 기준을 충족해야 한다. 0점 비율 차이의 연구실 단위 95% 신뢰구간에 개선 0이 포함되면 “개선 미확정 파일럿”으로 판정한다. 추가로 합집합 판정 풀에 관련 과목이 3개 이상 있는 연구실 중 90% 이상에서 B1이 3개 이상 반환해야 한다. 사람 검토가 없으면 채택 표현에 반드시 “Luna 기반 잠정”을 붙인다. 결측·어휘 미명중 층에서 무응답을 관련성 0점으로 단정하지 않는다. 기준 미달 또는 심사 기각이면 오류를 `identity`, `source_noise`, `role`, `teaching_depth`, `vocabulary_gap`, `missing_data`로 분류하고 규칙을 수정한다. 수정한 규칙은 원래 표본에 재채점하지 않고 별도 홀드아웃에서 다시 검증한다.

기존 다섯 실험의 “동일 결론”은 각각 원래 질문과 지표를 최종 데이터에서 다시 시험한 뒤에만 판단한다. 이 관계 실험 하나가 질의 해석·이유 생성·A/B·피드백 실험의 재현을 대신하지 않는다.
