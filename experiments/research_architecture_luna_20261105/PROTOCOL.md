# 관심·연구실·수강 과목에 기반한 연구 주제 추천 비교

실험 대상: 현행 `sunwoo` 논문·초록과 강의 설명을 사용한 연구실 3곳×서로 다른 수강 과목 2개, 총 6개의 작성자 제작 사례. 같은 연구실 내 두 사례는 논문·관심을 고정하고 수강 과목만 바뀐다. 각 과목이 현행 A 가이드에서 선택 가능한 20개 과목 안에 있음도 확인한다. 학생 질의는 합성이며 사례는 독립 학생 표본이 아니다.

세 비교안: 현재 `CuratedCatalog.guide`가 실제 반환하는 지금 시작/추가 준비 텍스트, Luna 단일 호출(논문·과목·관심을 주고 탐색 주제 요청), Luna 근거·검증형(동일 자료, 논문 사실과 과목 사실을 원문에서 추출, 후보 생성 후 부당 주장 제거 및 출처 확인). Luna는 사용자가 요청한 외부 frontier API 대용 subagent이며 실제 frontier API 사용과 동일하거나 frontier 모델이라고 주장하지 않는다. 생성 결과의 생성·검증은 같은 Luna 실행 내 수행하므로 독립 검증 모듈이 아니다. 입력은 공개 데이터와 합성 관심뿐이다.

생성 이전 고정 지표: Luna 심사자가 방법명·순위가 가려진 결과와 실제 입력을 보고 0/1/2점(미충족/부분/충족)으로 관심 적합, 연구실 근거 충실, 수강 내용 연결, 실행 가능 첫 단계, 불확실성·부당한 단정 방지를 채점한다. 각 답변에는 같은 평가기준을 적용한다. 사례당 다섯 항목 및 항목별 평균, 조건별 점수를 모두 보고한다. 주의: A는 현행 화면 문구의 두 열, 모델 출력은 생성된 가이드이므로 길이·형식이 다르며 눈가림 완전 보장은 불가능하다. 본 실험은 작은 표본의 탐색 실험이며 유의성이나 사용자 만족을 추정하지 않는다. 채점 에이전트는 학생이나 분야 전문가가 아니다. 후속으로 별도 Luna 평가자 한 명을 추가해 결과를 합치지 않고 일치율을 보고했다.

후처리 검증: 출력의 참조 논문/과목 ID가 해당 사례의 자료에 존재하는지 검사하고 미제공 ID를 보고한다. 구체적 인용문은 원문 일치 확인한다. 하위 에이전트 결과 원문과 프롬프트, 익명화 패킷 및 매핑·평가를 보존한다. 운영 서버·앱 데이터는 변경하지 않는다.
