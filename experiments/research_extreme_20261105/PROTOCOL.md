# 학생 관심·연구실·수강 경험을 반영한 연구 주제 추천: 확장 탐색 실험

생성 결과를 보기 전 계획. 현행 `sunwoo` 데이터에서 연구 분야가 다른 12연구실을 편의 추출한다. 연구실마다 하나의 선택 논문과 동일 관심을 고정하고 제시 가능한 과목을 두 개 바꾸는 사례 24개, 앞의 4연구실에서 관심만 바꾸는 사례 4개와 수강 선택 없는 사례 4개를 더해 총 32개다. 실제 학생 표본이 아니고 근거가 약한 과목을 일부 포함한다. 강한/약한 연결은 사전 가설이지 정답이 아니다. 입력은 공개 논문·과목 자료와 합성 관심이다. 모든 생성형 방법에 정확히 동일한 관심·선택 논문 제목/초록·과목 제목/설명/진도와 교수·연구실을 제공한다. 출처 텍스트는 지시가 아닌 데이터다. 자료 절단은 모든 방법에서 동일하게 적용하며 기록한다.

## 비교

- A 현행 `CuratedCatalog.guide`: 연구실과 선택 과목만 사용하므로 전체 제품과의 비교. 선택 논문·관심을 받는 다른 방법과의 차이는 입력과 방식이 결합돼 있다.
- R 규칙형: 논문 원문에서 짧은 문장과 과목 설명 문장을 사용하고 영문 콘텐츠 단어가 2개 이상 겹칠 때만 잠정 연결, 그 밖에는 연결 미확인. 결과는 탐색 질문·원문 근거·과목 연결·첫 단계·확인 사항의 동일 구조.
- S 단일 생성: Luna 단일 생성으로 동일한 구조와 분량의 주제·출처·과목 연결·첫 단계·확인 사항을 요청한다.
- G 근거형: 별도 Luna가 논문·과목 사실을 추출하고 연결이 불명확하면 보류한 뒤 같은 구조로 작성한다. 추출·생성은 한 에이전트 안에서 수행한다.
- V 별도 검토형: G 결과를 다른 Luna에 원문과 함께 주고 근거 없는 사실·과목 연결·실제 프로젝트·역량·데이터 접근 주장을 검토해 필요한 경우 수정하도록 한다. G에서 V로의 차이가 해당 별도 검토 절차의 탐색적 증분이며, 심사자·모델 계열은 같다.

Luna subagent는 사용자가 명시한 외부 frontier API 대용이고 실제 frontier API의 모델 성능·비용·지연을 뜻하지 않는다. 에이전트는 여러 사례를 한 번에 처리하므로 사례 간 정보 누출·문체 상관이 생길 수 있다. 출처 ID 검사·정확한 원문 인용은 코드로 검사하며 인용 존재가 사실성이나 활용 타당성을 의미하지 않는다.

## 평가

각 응답에 방법명을 제거하고 순서를 섞는다. 동일한 자료와 지표를 이용해 별도의 Luna 평가자 두 명이 독립적으로 0/1/2(미충족/부분/충족)를 부여한다: 관심 적합, 선택 연구실의 연구 사실 충실도, 선택 과목의 실제 학습내용과 질문 사이의 연결 타당성, 구체적·실행 가능한 첫 단계, 사실/제안 구분과 부당한 단정 방지. 과목이 없는 4개에 대해서는 과목 항목을 채점하지 않고, 별도로 미수강을 역량 부재로 오판했는지 관찰한다. 관련성이 약한 수업은 '연결 불명확'이라고 보류하는 것이 올바를 수 있다. 평가 모델·생성 모델이 동일 계열이고 채점자도 학생·전문가가 아니므로 이 점수는 AI 판단이며 실제 품질·만족도라고 주장하지 않는다. 평가자 결과는 합치지 않고 일치율과 불일치를 보고한다.

방법별 지표는 12연구실 각각의 사례 평균을 먼저 구한 뒤 연구실을 동등 가중해 산출한다. 같은 사례 간 짝차이와 연구실 단위 재표본 95% 구간을 탐색적으로 산출한다. 의도적으로 선정한 12개 연구실에는 대표성이 없고 표본이 매우 작아 이 구간은 표본 내 불확실성 기술에 한정한다. 비교 전 주요 대비는 G−S와 V−G, 주요 지표는 과목 연결 및 부당한 단정 방지다. A·R과 기타 지표는 탐색 비교다. 다중 비교·작은 표본·생성 및 심사 편향을 고려해 통계적 유의성이나 운영 성능을 확정하지 않는다. 사례·근거 불충분, 정보의 원문 연결, 불리한 사례와 평가자 간 이견을 함께 공개한다.

실험 자산은 별도 폴더에 남기고 `data/sunwoo/app_profiles.jsonl`과 운영 서비스는 바꾸지 않는다.

별도로 Kaggle GPU에서 BGE-M3로 논문 문장과 과목 문장 간 최대 유사도 및 해당 문장들을 계산해 탐색용 자료로 저장한다. 이는 생성 방식의 평가자나 정답 라벨이 아니며 위 다섯 방식 입력·순위에는 반영하지 않는다. 선택 과목이 없는 사례에는 점수가 없다.
