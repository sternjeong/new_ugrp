# 사전 계획: Sonnet 없이 A5에 가까운 검색 (2026-11-09)

결과를 보기 전에 작성했다. 뒤에 바꾼 것은 REPORT.md에 따로 적는다.

## 질문
실행 시점에 프런티어 LLM을 부르지 않고(작은 모델과 사전 계산만으로) A5(Sonnet 해석)에 얼마나 가까워질 수 있는가.

## 분해 결과 (ablation.json, 기존 50개)
A4 대비 추천 질의 nDCG@5 이득은 검색문 재작성이 +0.131, 긍정/부정 분리가 +0.008이다. 적합도에서 의도 판별은 +0.060이다. 그래서 검색문 재작성과 의도 판별만 대체한다.

## 후보 부품
**검색 표현**
- T: NLLB-200 한→영 번역을 원문에 덧붙임 (자료가 대부분 영어)
- C: 연구 용어 사전 벡터 최근접 확장. 사전은 연구 분야명·OpenAlex 분류·과목명·논문 제목의 구절이다
- P: 유사 피드백(Rocchio). 1차 상위 조각의 중심을 질의 벡터에 섞음

**검색 신호** (모두 RRF로 결합)
- D: 조각 BGE-M3 dense 집계 (A4와 같음)
- S: BGE-M3 sparse
- B: BGE-M3 ColBERT (dense 상위 200조각 재채점)
- R: bge-reranker-v2-m3 (A6처럼 순서를 대체하지 않고 순위 하나로 융합)
- Q: Doc2Query. Qwen2.5-7B가 사전에 한 번 연구실별 한국어 키워드·학생 질문을 만들어 색인에 추가한다. 실행 시점 LLM은 없고 이 문장은 화면에 근거로 보이지 않는다.

**의도 판별**
- E: BGE-M3 예문 분류. `intent_exemplars.json`은 이 계획과 함께 작성했고 시험 질의를 보기 전에 고정했다.
- N: 다국어 NLI 제로샷(mDeBERTa-v3-base-mnli-xnli)
- 규칙: 현재 게이트 + '피하고 싶' 부정 보강

## 절차
1. **개발 세트:** 기존 50개. 부품 선택과 가중치·임계값 조정은 여기서만 한다. 기존 등급을 재사용하고, 새로 상위에 든 미평가 연구실은 추가 평가한다.
2. **시험 세트:** 시스템을 모르는 Sonnet이 쓴 새 질의 50개(유형 분포는 개발 세트와 같음). 후보를 고정한 뒤 한 번만 평가한다.
3. 전진 선택으로 개발 세트 적합도를 최대화해 후보를 고정한다. 추가 이득이 0.005 미만인 부품은 넣지 않는다.
   - **N1:** 실행 시 LLM 없음, Qwen 생성물도 쓰지 않음
   - **N2:** N1 + Doc2Query(Qwen 사전 1회)
4. 시험 세트 비교: A0(현행, 동명이인 수정 포함), A4, A5, N1, N2.

## 평가
기존과 같다. Sonnet 판정자 5명, 질의별 풀 + 무관 대조군 2곳, 적합도 = 추천 질의 nDCG@5 / 거절 질의 정답 여부. 차이는 질의 단위 bootstrap 95% 구간으로 보고한다. Sonnet은 판정과 A5 비교 기준으로만 쓴다.

## 판정 규칙
시험 세트에서 N1 또는 N2가 A5와의 차이 구간에 0을 포함하면 '대체 가능'으로 본다. 구간이 A5보다 낮은 쪽에 있으면 얼마나 좁혔는지(A4 대비 회복률)를 보고한다.

## 한계
판정자가 Sonnet이어서 Sonnet 재작성에 유리할 수 있다. 질의 작성자도 LLM이다. 시험 세트는 50개로 작다.
