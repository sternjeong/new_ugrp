## 부품별 효과 (개발 세트, 전진 선택)

기준 0.706 → 의도 게이트 0.738 → 번역 0.747 → 번역문 사전 검색 0.752 → 리랭커 융합 0.761 → 유사 피드백 0.768. A5는 0.875. 단독 추가 효과가 작거나 해로운 부품: BGE-M3 sparse, ColBERT, 용어 사전 최근접 확장, NLI 게이트(mDeBERTa, 예문 정확도 76%). 번역 품질이 한계여서 `집적회로`는 "cumulative circuit"으로 옮겨졌다.

## 계획에서 달라진 점

- 예문 임베딩 게이트는 개발 세트에서 싫어함이 든 문장을 거르는 문제가 확인되어, 규칙이 싫어함을 찾은 입력에는 적용하지 않도록 바꿨다. 임계값은 예문 leave-one-out에서 정한 값(0.05) 그대로다.
- Qwen 색인 단계가 GPU 메모리 부족으로 실패해 GPU 2장으로 나눠 다시 돌렸다.
- 시험 질의는 전략을 고정하기 전에 화면에 출력되어 작성자가 보았다. 시험 질의로 조정한 것은 없다.

## 한계

판정자가 Sonnet이어서 Sonnet 재작성에 유리할 수 있다. 시험 질의도 LLM이 썼고 50개로 작다. 예문 중 `과학`은 시험 질의와 같고, `넷플릭스 드라마 추천해줘`는 시험 질의의 일부와 겹친다. 동명이인 논문이 조각 색인에는 남아 있어 모든 전략에 공통으로 작용한다. N1·N2는 서비스에 구현하지 않았고 워커 메모리·지연은 측정하지 않았다.

## 서비스 구현 확인 (N1, 2026-11-09)

서비스 코드에 N1을 넣고, 실제 워커 코드와 모델을 Kaggle T4에서 돌린 응답을 서비스 엔진에 재생해 같은 시험 세트로 다시 쟀다(`service_replay.py`, `service_judge.py`, `service_metrics.json`, `service_timing.json`).

| 항목 | 값 |

연구와 다른 점: 리랭커는 조각 점수 상위 50곳만 채점한다(개발 세트 적합도: 전체 0.768, 50곳 0.768, 30곳 0.767, 20곳 0.754 — `topk_dev.json`). 동명이인 논문 조각 40개는 색인에서 뺐다. 사전 검색 카드에 의미 순위 뒷받침 조건과 동명이인 필터를 그대로 유지했다. 표시용 문장 정리(`curri/text_cleanup.py`)와 문장 선택 변경도 포함된 코드로 쟀다. 새로 나온 연구실 11쌍은 같은 판정단으로 채점했다($0.99). Kaggle 대기열 시간은 포함되지 않았다(이번 작업은 약 45분 대기했다). 동시 요청 시 지연은 재지 않았다.

추가 수정: 사용 점검에서 `좋아하는 주제 + 피하고 싶은 것` 문장의 잘못된 거절이 확인되어, 관심 표현과 회피 표현이 함께 있으면 거절 판단을 건너뛴다. 시험 세트에서 영향을 받는 질의는 h19, h20이고 h19만 순위가 바뀐다. h19 순위를 연구 데이터로 계산해 넣으면 적합도 0.795(판정 없는 3쌍은 0점 처리), 잘못된 거절 0건이다. 이 변경 뒤에 h19를 실제 워커로 다시 돌리지는 않았다.
