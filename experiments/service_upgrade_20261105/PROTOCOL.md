# 교과목 표현과 담당 교수 검색: 사전 실험 계획

2026-11-05, GPU 실행 전에 고정. 현재 정제본에서 추천 가능한 연구실의 담당 교수 연결이 있고 고유한 제목을 가진 과목 중 시드 20261105로 200개를 추출한다. 과목마다 제목과 두 개의 고정 문장 틀을 결합한다. 학생이 작성한 질의가 아니며 정답은 `courses.jsonl`의 명시된 담당 교수 연구실만이다. 담당 교수가 반드시 사용자의 연구 관심에 가장 적합하다는 뜻은 아니다. 여러 담당 교수 중 하나라도 상위에 있는지를 측정한다.

현재 서비스의 BGE-M3 + 사전 검색 + 과목 연결을 그대로 기준선으로 한다. 비교안은 해석 후 구절에서 과목명을 찾기 전에 원문에서 정규화하지 않은 전체 과목 제목의 최장 일치 하나를 찾아, 동일한 `course_labs`와 융합을 사용하는 방식이다. 원문 문자열 포함으로 식별하므로 우연히 제목이 포함된 연구 관심 문장에서 오탐할 수 있으며, 이 데이터는 그것을 측정하지 못한다. 비교안은 실험 코드에만 둔다. 교수 링크는 기준선과 비교안이 모두 이미 사용할 수 있는 정보이므로 목표에 대한 누출이며, 이 실험은 독립 관련도 평가가 아니라 명시적 연결을 노출하는 기능의 회귀·강건성 진단이다.

질의별 담당 교수 hit@1, hit@5, 과목 식별률을 보고한다. 두 문장 유형을 따로 분석하고, 전체 효과의 불확실성은 과목 단위 쌍체 bootstrap(2,000회, 시드 20261105)으로 구한다. 200개 과목을 함께 선정했으므로 두 문장은 독립 표본이 아니다. GPU에서 기존 문서 벡터와 동일 BGE-M3 모델로 구절을 인코딩해 연구실별 최대 유사도를 만든다. 순위 융합은 로컬 현행 코드를 사용한다. 정답에 사용한 교수 연결의 품질이나 비담당 연구실의 관련도는 판정하지 않는다. 비교안은 사후 튜닝하지 않는다.
