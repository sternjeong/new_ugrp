# Sonnet 기반 연구주제 생성과 평가 신뢰도 실험

## 사전 계획

앞선 `research_extreme_20261105` 실험의 심사 혼동과 일반적인 행동에 만점을 준 문제를 보강한다. 기존 편의 추출 12연구실의 `course1` 12개, 처음 네 연구실의 `course2`, `interest`, `none` 각각 네 개로 총 24상황이다. 자연어 관심은 논문을 보고 만든 합성 질의이며, 실제 학생 표본이나 새로운 연구실 보류셋은 아니다. 각 논문·과목 원문, 길이 제한, 각종 근거는 이전에 동결한 `cases.json`을 재사용하며 정확한 입력 SHA를 기록한다. 동일 연구실 안에서 한 요인만 바뀌는 상황을 포함한다. 현실성 및 일반화는 주장하지 않는다.

Sonnet API 대용으로 도구를 끈 `claude -p --model sonnet --tools '' --no-session-persistence` 프로세스를 **상황별로 별도 실행**한다. 구독 인증을 사용하는 CLI이지 별도의 Anthropic API 키나 네이티브 collaboration Sonnet 모델이 아니다. 응답의 실제 모델 ID, 시간, 사용량 및 실패·재시도를 보존한다. 소스는 비신뢰 데이터로 취급한다.

## 비교

- A 현재 서비스 `CuratedCatalog.guide` 실제 출력. 관심과 선택 논문이 입력에 없으므로 생성형과 입력이 다르며 제품 기준선으로만 사용한다.
- S 동일 Sonnet의 단일 생성: 공통 구조로 관심, 선택 논문, 과목 설명을 근거로 질문·첫 활동을 제안.
- G 동일 Sonnet의 근거 추출 + 생성: 같은 입력·출력 스키마에서 별도의 사실/제안 분리, 과목 연결 보류, 원문 정확 인용을 지시. 추출과 생성은 하나의 호출이다.
- V G 응답에 대해 **다른 독립 Sonnet 프로세스**가 같은 원문과 함께 주장의 오류와 근거를 검토하고 필요한 경우 수정. 검토기 실패나 무효 출력은 숨기지 않는다.

G−S와 V−G의 효과는 탐색 비교다. S/G/V 모두 같은 출력 필드, 같은 문맥과 길이 제한을 사용한다. V는 호출이 하나 더 필요하므로 같은 컴퓨팅 예산에서의 우위가 아니다. 단일 모델·샘플링 1회이며 모델의 생태적 정확도나 사용자 만족도를 의미하지 않는다.

## 평가와 기준 확인

각 답변과 동일한 입력을 사용해 방법명·답변 순서를 숨기고 **답변별 별도의 Sonnet 프로세스**로 독립 2회 채점한다. 평가자는 해당 답변·입력만 보고 0/1/2점: 관심 반영, 연구실 논문/소개 사실, 과목 실제 내용과 질문의 타당한 연결, 논문·관심에 구체적인 첫 단계, 과도한 단정 방지. 과목 미선택은 과목 항목 null. 해당 과목과 연구의 연결이 증명되지 않으면 보류를 허용한다. 각 판정에는 원문 근거와 이유를 요구한다. 방법마다 24개, 총 96개 응답의 192회 채점이며, 실패는 보존하고 성공 응답만 골라 비교하지 않는다.

심사기 기준 확인은 제품 구조상 선택 과목의 실제 학습 내용 연결을 출력하지 않는 A에서, 수강 과목이 있는 20개 중 `course=0`으로 맞힌 비율과 범용 첫 단계의 `action<=1` 비율을 보고한다. 이는 코드로 확인 가능한 **한정된 기준**이지 사람 판정의 대체가 아니다. 심사자 동일계열 편향, 스타일로 방법을 추정할 가능성, 학생·전문가가 아니라는 한계를 유지한다. 주요 지표는 과목 연결과 구체적 첫 단계, 연구실 12개를 동일 가중하고 bootstrap 구간은 편의 표본의 기술 통계로만 보고한다. 두 채점자의 점수와 완전 일치율을 별도로 남긴다. 편리한 평가자 하나만 고르지 않는다.

추가로 G/S/V의 인용된 논문과 과목 원문 인용을 정규화 공백 처리 후 입력과 **문자열 대조**한다. 인용 문자열이 원문에 존재해도 그 논리적 연결이 타당하거나 수강자가 숙련했다는 뜻은 아니다. 인용 미존재, ID 누락, 출력 포맷 실패, 재시도는 모두 분모에 포함한다. 실제 이용 지표·현재 데이터 접근 가능성·논문 전체 의미는 이 자료에서 판정하지 않는다. 모델 판정이 보류를 과도하게 보상하는지도 수동 사례 감사로 점검한다. 운영 서비스·앱 프로필은 수정하지 않는다.
