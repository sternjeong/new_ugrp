# 연구주제 추천: Sonnet 생성 및 심사 신뢰도 보강 실험

## 결론

같은 24개 상황에서 Sonnet 단일 생성(S)과 사실·과목 근거를 분리해 지시한 Sonnet 생성(G)을 비교했다. 두 Luna 평가 패널의 **과목 연결 G−S 차이는 0.000점과 −0.139점(2점 만점)**이었다. 기존 근거형 지시가 단일 생성보다 우수하다는 결과는 나오지 않았다. 별도 검증형(V)은 Sonnet 사용 한도로 24개 중 6개만 완료해 공정 비교하지 못했다. 성공한 6개만 뽑아 V가 낫다고 판단하지 않는다.

앞선 실험의 AI 채점 혼동에 대응해 기존 가이드의 과목 연결 부재를 점검했을 때 Luna 패널 둘 모두 수강 사례 20/20을 0점으로 평가했다. 이는 해당 기준의 한정된 점검 통과일 뿐 나머지 채점이 정확하다는 뜻이 아니다. 모든 생성형 답변의 단정 방지를 두 패널이 만점으로 평가한 항목은 구분력이 없었다. 사람 전문가·실제 학생의 관련도와 유용성 평가는 여전히 없다.

## 자료와 방법

- 앞선 `research_extreme_20261105`의 12개 연구실을 재사용했다. 연구실별 과목 선택 사례 12개와 앞의 4개 연구실에서 다른 과목·다른 관심·수강 과목 없음 사례를 각 4개 추가해 24상황이다. 동일 연구실의 조건은 독립 표본이 아니며 합성 관심은 논문을 보고 작성해 실제 학생과 다르다. 새로운 보류 연구실 시험셋이 아니다.
- S는 논문·과목 원문과 관심으로 질문을 생성하는 단일 지시, G는 원문 근거 추출과 사실·제안 구분을 더 지시하는 단일 호출이다. 구조화된 출력 필드와 입력은 같고 논문·과목의 실제 원문 인용을 요청했다. V는 G를 별도 Sonnet 호출로 검토·수정한다. 현행 A는 실제 서비스 가이드이며 선택 논문과 관심을 받지 않으므로 제품 기준선이다. A 대 생성형은 모델만의 효과가 아니다.
- `claude -p --model sonnet --tools '' --no-session-persistence`를 사례별 독립 프로세스로 사용했다. 반환된 모델 ID는 `claude-sonnet-5-5`다. 이는 사용자가 요청한 Sonnet 대용 실행이며 OAuth 구독 CLI를 통한 호출로, 별도 Anthropic API 키를 쓴 실험은 아니다. 실제 토큰·시간과 리스트 기준 비용 추정은 `calls/`에 기록돼 있으며 실제 청구액을 뜻하지 않는다.
- S/G의 48개 호출은 전부 성공했다. V는 24회 중 6회 성공하고 18회는 **5시간 사용 한도** 메시지로 실패했다. 실패를 기록했으며 무작위 누락이 아니므로 V 성능을 계산하지 않는다. 계획한 Sonnet 심사 192회도 실행할 수 없었다.
- Sonnet을 우선 사용하고, 한도 이후에는 이전 요청에서 허용된 Luna subagent로 72개 A/S/G 답변을 방법명 없이 평가했다. 24개씩 나눈 세 에이전트가 한 패널이며 같은 일을 별도 세 에이전트로 반복했다. 이는 사례별 독립 Sonnet 채점이 아니라 **사후 변경된 Luna 배치 심사**이고, Luna도 평가 대상 답변의 형식에서 방법을 추측할 수 있다. 결측 과목 점수 한 건을 자동 `null` 보정했으며 원본과 보정 기록은 [luna_analysis.json](luna_analysis.json)에 보존한다.

## 검증 가능한 출력과 판정

| 검사 | S 단일 생성 | G 근거 분리형 |
|---|---:|---:|
| 성공적으로 생성 | 24/24 | 24/24 |
| 입력 논문 초록에 해당 문자열이 존재하는 인용 | 24/24 | 24/24 |
| 선택된 과목의 **설명·진도 본문**에 해당 문자열이 존재하는 인용 | 19/20 | 20/20 |
| 과목이 없을 때 과목 ID를 비움 | 4/4 | 4/4 |

S의 불일치 1건은 과목 본문 대신 실제 과목 **제목** `Engineering Project Management`를 인용한 사례다. 제목이 허구라는 뜻은 아니며 사전에 정한 본문 인용 조건에는 맞지 않는다. 인용 문자열이 원문에 있더라도 해당 개념과 연구 질문의 연결이 옳거나 학생이 숙련했다는 뜻은 아니다.

| 지표(0~2점, 연구실 동일 가중) | A 패널 1 / 2 | S 패널 1 / 2 | G 패널 1 / 2 |
|---|---:|---:|---:|
| 관심 반영 | 0.00 / 0.00 | 2.00 / 2.00 | 2.00 / 2.00 |
| 연구실 사실 | 0.71 / 1.42 | 2.00 / 1.96 | 2.00 / 1.96 |
| 선택 과목 내용 연결 | 0.00 / 0.00 | 1.67 / 1.83 | 1.67 / 1.69 |
| 구체적 첫 단계 | 0.00 / 0.71 | 1.90 / 1.67 | 1.73 / 1.65 |
| 단정 방지 | 2.00 / 2.00 | 2.00 / 2.00 | 2.00 / 2.00 |

G−S의 과목 연결 차이는 패널 1에서 0.000 [0.000, 0.000], 패널 2에서 −0.139 [−0.389, +0.056]이다. 첫 단계 차이는 각각 −0.167 [−0.396, +0.021], −0.021 [−0.354, +0.313]이다. 구간은 편의 선정한 12연구실 재표본의 95% 구간으로 학생 모집단에 일반화할 수 없으며, 평가 지표와 패널 자체가 사후 대체되었다. 첫 패널은 선택 과목이 있는 20개 사례에서 S와 G에 모두 같은 과목 점수를 주었다. 이런 동률은 두 답변의 품질 동등성을 증명하지 않는다.

두 패널의 전체 답변 기준 과목 평가 일치는 47/60, 이차 가중 카파 0.865이나, 이는 두 패널 모두 0점을 준 A의 20건을 포함한다. S에 대해서는 14/20, G에 대해서는 13/20만 정확히 일치했다. 같은 Luna 계열 평가라는 공통 편향도 남는다. 현행 A에 대한 기준 확인은 두 패널 모두 선택 20개에서 과목 0점 20/20, 첫 단계 1점 이하 20/20이었고, 별도의 Sonnet 예비 점검 4건도 과목 0점이었다. 단정 방지는 A/S/G 72답변 모두 양 패널 만점이라 안전성 검증으로 해석하면 안 된다.

사후 단일 Luna 패널의 S/G 좌우 블라인드 쌍대 비교는 G 11승, S 10승, 동점 3건이었다. 한 쌍을 한 AI만 보았으며 기존 데이터에 대한 사후 분석이라 독립 확인 실험이 아니다. 개별 결과는 [pair_analysis.json](pair_analysis.json)이다.

## 사례와 추가 주의

`case_03_course2`에서 G는 골격 행동 인식 논문과 고급 알고리즘 수업을 연결하면서 골격을 그래프로 보는 전처리를 **제안**으로 분리하고, 논문이 그래프 알고리즘을 명시하지 않아 인식 성능과의 직접 연결은 불명확하다고 밝혔다. 이는 수강했다고 해서 관련 지식을 숙련했다고 주장하지 않는 연결이다. 반면 이러한 보류 문장이 항상 옳다는 의미는 아니며, 접근 가능한 실제 데이터, 계산 자원, 연구실의 현재 프로젝트는 초록만으로 확인할 수 없다.

앞선 실험의 잘못된 교차 사례 채점을 완전히 배제했다고 말할 수 없다. 이번 Luna 심사자는 한 무선택 사례를 0점으로 반환했다가 분석 단계에서 null로 보정했고, 일부 내용 점수는 패널마다 달랐다. 실제 학생 표현과 학과별 전문가의 원문 판정이 없는 상태에서 출력 타당성·첫 단계 수행 가능성·사용자 만족을 입증했다고 주장하지 않는다.

## 다음 판단을 보강할 절차

1. Sonnet 한도 회복 후 실패한 V 호출과 별도 Sonnet 심사를 **기존 입력과 출력 및 실패 로그를 보존하면서** 재개한다. 미완료 18건만 성공 사례로 취급하지 않는다. 재개 시각이 다르면 모델 및 데이터 버전 차이를 기록한다.
2. 생성·검증·심사 시 각 호출을 한 사례로 분리하고, 코드로 검증 가능한 고정 정답 대조(현행 과목 연결 0, 존재하지 않는 출처 ID, 조작된 인용문 등)를 평가 묶음에 섞어 심사자의 오탐·누락을 직접 측정한다. 인용 존재 검사와 의미상 뒷받침을 구분한다.
3. 실제 학생이 작성한 질의 및 선택 과목과 연구실을 동의하에 수집하고, 연구실 단위로 개발/미노출 시험을 분리한다. 해당 분야 대학원생과 학부생이 방식을 모른 채 근거 충실·과목 연결·첫 단계·유용성을 각각 판정하고 불일치를 공개한다. 이 평가 전에는 운영 성능을 확정하지 않는다.
