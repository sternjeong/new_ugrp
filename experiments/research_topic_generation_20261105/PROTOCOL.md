# 관심·연구실·수강 경험 기반 연구 질문 생성: 예비 실험

GPU 실행 전 계획. 실제 `sunwoo` 논문과 과목 근거를 사용한 작성자 제작 3개 사례에 대해 기준, 관심만 변경, 과목만 변경, 수강 선택 없음의 네 조건을 만든다. 같은 논문과 연구실을 유지해 총 12조건이며 3개 사례는 실제 학생 표본이 아니다. 두 방법에 동일 근거와 같은 소형 공개 생성 모델을 사용한다. A는 포괄적인 단일 지시, B는 연구 근거/관심/과목 학습 내용/제안과 미확인 사항을 분리하는 규칙을 지시한다. 선택한 과목과 관계가 없으면 관계가 없다고 하고 미수강은 역량 부족으로 단정하지 않는다.

표본 및 프롬프트를 생성 전 고정한다. 모든 결과를 보존하며 비어 있는 결과도 분모에 넣는다. 1차는 빈 출력, 제공 논문·과목 ID 언급률, 제공되지 않은 ID 언급률, 관심·수강·수강 없음 조건에서 응답 변화를 자동 측정한다. 이것들은 품질·연결의 진위가 아니라 형식과 민감도 진단이다. 대응 조건은 주제 변화가 무조건 좋다는 뜻이 아니므로 텍스트 변화율을 개인화 정확도라고 부르지 않는다. 의미적 정확성과 구체성은 방법을 아는 작성자의 사후 소표본 점검으로 구분하고 독립 사용자 평가로 주장하지 않는다. 현재 앱 가이드와도 직접 비교한 것이 아니다.

공개 생성 모델은 frontier API가 아니며 개인정보를 포함하지 않은 실제 공개 논문/과목 자료와 합성 관심만 Kaggle에 전달한다. 단일 실행, 단일 모델, 개발자 작성 사례라 통계적 일반화 및 사용자 만족을 증명하지 않는다. 모델 원문에서 없는 연구·자격·데이터 접근은 추론/확인 필요로 표시한다.
