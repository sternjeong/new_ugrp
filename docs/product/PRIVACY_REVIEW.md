# 개인정보 처리 검토와 구현 대응 (2026-11-07)

이 문서는 운영 준비를 위한 정리다. 법률 자문이 아니므로, 실제 학생과 대학원생을 받기 전에 학교 개인정보 담당 부서나 전문가에게 검토를 받는다. 기준은 2023-09-15부터 시행된 개정 개인정보 보호법과 「개인정보의 안전성 확보조치 기준」이다.

## 1. 확인된 사실

- **서비스 서버는 Oracle Cloud 일본 도쿄 리전(ap-tokyo-1)에 있다.**
  - 2026-11-07 인스턴스 메타데이터로 확인했다.
  - 회원 정보 전체가 국외에 보관되므로 **국외 이전(보관)**에 해당한다.
  - 관리자 VM도 같은 리전에 만들면 마찬가지다.
- **국외 처리:**
  - 의미 검색: 검색 문장이 Kaggle(Google LLC, 미국)로 간다.
  - AI 가이드: 검색 문장, 선택 과목, 학과·학년이 개발 VM의 Claude CLI를 거쳐 Anthropic PBC(미국)로 간다.
  - 논문 쉬운 요약: 공개 초록만 보내므로 개인정보가 아니다.
- 학생이 쪽지·커피챗을 보내면 이름·이메일·프로필이 그 선배에게 전달된다.

## 3. 채워야 할 슬롯 (`.local/privacy.json`)

```json
{
  "operator": "3분커리 팀 (POSTECH UGRP)",
  "officer_name": "홍길동",
  "officer_position": "팀장",
  "officer_email": "privacy@example.com",
  "officer_phone": "010-0000-0000",
  "effective_date": "2026-11-15"
}
```

- 비어 있는 항목은 처리방침에 `【입력 필요】`로 보인다.
- 관리자 화면 개요에서도 비어 있는 항목을 확인할 수 있다.
- `hosting_region`은 확인된 값(일본 도쿄)이 기본으로 들어가 있다.

## 4. 남은 판단

1. **서버 리전.** 국내 리전으로 옮기면 국외 보관 고지가 빠지고 학생의 부담도 준다. 옮기지 않으면 지금처럼 필수 동의 문구에 국외 보관을 밝힌다.
2. **AI 처리 경로.** 지금은 개발 VM의 구독 CLI로 처리한다. 정식 운영에서 Anthropic API를 쓰면 처리방침의 처리 경로 설명을 그에 맞게 고친다. 국외 이전 항목 자체는 같다.
3. **더미 데이터.** 더미 선배 30명과 후기는 시연용이다. 실사용을 시작하면 표시를 끄거나(`--no-demo-data` 후 삭제) "예시"라고 밝힌다.
