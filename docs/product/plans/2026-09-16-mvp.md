# 3분커리 로컬 MVP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The current task is executed inline; no agent delegation is requested.

**Goal:** 실제 데이터로 첫 연구실 전체 탐색, 두 번째 연구실 로그인, 저장·메모까지 실행되는 로컬 프로토타입을 만든다.

**Architecture:** Python 표준 라이브러리 HTTP 서버, SQLite 저장소, 한국어 HTML/CSS/JavaScript 화면. JSONL을 읽는 근거 기반 추천 모듈과 인증·저장을 분리한다. 외부 모델 호출 없이 명시적 주제 사전과 본문 구절로 추천하고, 최종 가이드는 근거를 연결한 탐색·준비 제안으로 한정한다.

**Tech Stack:** Python 3.11+, SQLite, vanilla JavaScript; unittest. 운영 배포용 서버가 아니라 로컬 사용성·데이터 연결 검증용이다.

**Spec:** [제품 기준](../PRODUCT_PLAN.md)

## Global Constraints

- 교과목 419건과 collected 연구실만 사용. 원본 파일을 수정하지 않는다.
- 첫 연구실 상세는 비회원 전체 이용; 두 번째 다른 연구실부터 서버에서 로그인 요구. 결제 없음.
- 초기 입력은 관심·고민(필수)과 목적(연구참여/진학/탐색 중 선택). 학번·전체 이력·프로젝트 입력 없음.
- 근거 없는 모집·환경·공식 연구 프로젝트·숙련도 주장을 만들지 않는다.
- 관심의 관련성으로 목록을 정렬; 준비 부족으로 후보를 제외하지 않음. 개인별 n축 학습·LLM 추천은 이 프로토타입의 구현 범위로 주장하지 않는다.
- 기존 기본정보·인증 등 미정 사항은 이 문서의 프로토타입 선택으로 기록하며 제품 전체의 영구 제약으로 삼지 않는다.

## 1. 근거와 가이드

Files: `curri/catalog.py`, `tests/test_catalog.py`.
Interfaces: `Catalog(data_dir)`, `search(interests)`, `detail(lab_id)`, `guide(lab_id, selected_course_ids)`, `resolve(lab_id)`.

- [x] 직접·확장 관심, 부재 관심, 제외 자료, 공동 홈페이지, 잘못된 수강 ID, 무수강·일부 수강 가이드 테스트를 먼저 실행한다.
- [x] 한영 주제 사전과 단어 경계 매칭, 실제 본문 구절 및 URL을 사용한다. 모든 일치 후보를 반환한다.
- [x] 동일 홈페이지는 통합 표시하며 현재 확인된 ML 공동 홈페이지도 명시적으로 연결한다. 과목 복합 코드는 원문 한 항목으로 유지한다.
- [x] 선택 연구실에 연결되는 모든 과목을 반환하고, 가이드는 공통 주제와 과목별 수강 근거로 구성한다. 정밀 수행 가능성·성공 확률은 출력하지 않는다.

## 2. 서버의 인증·저장 경계

Files: `curri/store.py`, `tests/test_store.py`.
Interfaces: `Store(db_path)`, sessions and accounts; `open_lab`, `save_exploration`, `authenticate`, `snapshot`.

- [x] 익명 두 번째 연구실 거부, 같은 연구실 재방문, 경쟁 요청, 타인 저장 접근 불가, 로그인 승계 및 비밀번호 실패 테스트를 작성·실행한다.
- [x] SQLite 트랜잭션으로 최초 연구실을 고정한다. 익명 세션은 30일 유지하고 새 세션에서는 재시작 가능하다(엄격한 남용 방지 아님).
- [x] 이메일·비밀번호 로컬 계정 사용. 이메일 인증·복구는 없음. scrypt 해시, 임의 토큰 HttpOnly/SameSite 쿠키, 로그인 시 회전, 서버 권한 검사를 적용한다.
- [x] 비회원도 첫 결과·메모 저장 가능. 로그인 시 계정으로 승계. 같은 연구실 결과가 있으면 로그인 직전 익명 결과를 우선하고 기존 결과는 이전 버전으로 보존한다.

## 3. API와 화면

Files: `curri/server.py`, `curri/__main__.py`, `curri/static/index.html`, `curri/static/app.js`, `curri/static/styles.css`, `tests/test_http.py`.

- [x] 실제 HTTP 서버로 세션→검색→첫 상세→가이드→저장→두 번째 거부→로그인→두 번째 성공을 검증한다.
- [x] `GET /api/session`, `POST /api/search`, `/api/explore`, `/api/guide`, `/api/save`, `/api/register`, `/api/login`, `/api/logout` 제공. 모든 사용자 상태는 세션에서 읽고 소유자 ID를 클라이언트에서 받지 않는다.
- [x] 관심 화면, 모든 후보 목록, 한 연구실 상세, 과목 선택, 두 갈래 가이드, 저장 목록·메모, 로그인 대화상자를 연결한다.
- [x] 실패·빈 결과·로딩·새로고침·로그인 취소를 처리하고 외부 원문은 안전한 링크로 연다. 선택 과목은 초안도 저장한다.
