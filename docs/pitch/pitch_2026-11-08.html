03 · 로그인·세션·계정
ACCOUNTS & SESSIONS

로그인·세션·계정 관리

세션과 로그인

  • 첫 방문에 30일짜리 세션 쿠키(HttpOnly, Secure, SameSite=Lax). DB에는 토큰의 해시만 저장
  • 비회원은 연구실 1곳까지 탐색 → 두 번째부터 로그인 요청, 가입 시 기존 탐색을 계정으로 합침
  • 비밀번호는 scrypt(사용자별 salt) 단방향 저장 · 로그인 시도 IP당 5분 15회 제한
  • 같은 사이트 요청만 허용(Origin 검사), 엄격한 CSP로 외부 스크립트 차단

계정 기능 (SMTP 연결 후)

  • 6자리 이메일 인증 코드(15분) · 비밀번호 재설정 링크(1시간, 1회용, 모든 기기 로그아웃)
  • 알림 설정: 새 쪽지 · 만남 · 지켜보기 · Q&A 답변
  • 탈퇴: 즉시 삭제, 상대가 받은 쪽지는 ‘탈퇴한 사용자’로 익명화
  • 차단·신고: 쪽지·후기·질문·답변 단위, 운영자 처리

선배(대학원생) 인증

  • @postech.ac.kr 가입 + 이메일 인증 → 연구실·과정·연구 분야·월 문의 상한·가능 시간 신청
  • 운영자가 콘솔에서 승인/반려(결과 메일) → ‘인증 선배’ 배지
  • 선배 이메일은 본인이 공개를 고른 경우에만 노출

개인정보 동의

  • 필수: 이용 안내 · 수집·이용과 국외 보관(서버가 도쿄) · 만 14세 이상

  • 커피챗 전 “내 정보가 이 선배에게 전달” 별도 동의 · 처리방침 /privacy

07 · 방법 선택 근거
EVIDENCE

왜 방법 R인가: 교수 페르소나 평가

6개 학과 연구실 × 수강 조건 2개 = 12사례. 그 연구실 교수 역할의 Sonnet 판정자 5명이 순서를 섞은 6개 안(5개 방식 + 다른 연구실 대조군)을 평가.

방식종합 (1~5)교수 수용률연구실 적합사실 근거첫 단계시간 분할 MRR*
A 기존 고정 가이드2.170%3.053.321.020.48
L Sonnet 단독 (논문 없음)4.0387%4.123.904.130.56
R 최근 논문 + Sonnet (채택)4.31100%4.774.584.620.73
RS 점수로 고른 논문 + Sonnet4.0297%4.474.124.050.56

대조군 (다른 연구실 답)1.390%1.001.032.25–

판정 신뢰도

판정자 간 Krippendorff α 0.88~0.97. 대조군을 꼴찌(연구실 적합 1.00)로 걸러냄.

* 시간 분할 검사

생성기에는 2024년 이전 논문만 주고, 결과가 그 연구실의 2025년 이후 실제 논문과 가까운지 143개 연구실 중 순위로 측정.

한계

생성·판정 모두 Sonnet(자기 선호 가능) · 사람 판정 없음 · 6개 연구실. 실제 학생 피드백으로 계속 검증합니다.

발표 포인트 · 규칙으로 논문을 고르는 RS는 오히려 나빴습니다(한국어 관심과 영어 초록의 단어가 안 겹침). 최근 논문을 그대로 주는 단순한 방식이 가장 좋았습니다.
