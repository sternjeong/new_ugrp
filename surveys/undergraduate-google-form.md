# 학부생용 Google Forms 설계

## 폼 제목과 소개

**제목:** 연구실 선택 경험과 정보 수요 조사 — 학부생 대상

**소개문(복사하여 사용):**
안녕하세요. UGRP 팀은 학부생이 연구실을 선택할 때 어떤 정보를 필요로 하는지 알아보고 있습니다. 현재 학부생이라면 연구참여 경험이 없어도 응답할 수 있습니다. 연구참여에는 학부연구생, 연구실 인턴, 단기 연구 프로젝트를 포함합니다. 수업 실습만 참여한 경우는 제외합니다.

예상 소요 시간은 약 3~4분입니다. 이름, 이메일, 소속 연구실명은 수집하지 않으며, 응답은 서비스 기획을 위한 통계 분석에 사용합니다. 응답은 자율적으로 진행하며 원하지 않으면 제출하지 않고 종료할 수 있습니다. 정답은 없으니 본인의 경험에 가장 가까운 답을 선택해 주세요.

**제출 후 메시지:** 응답해 주셔서 감사합니다. 연구실 선택에 필요한 정보를 이해하고 UGRP 서비스를 설계하는 데 활용하겠습니다.

> 소요 시간은 설계상 추정치입니다. 배포 전 모바일로 시범 응답해 보고 수정하세요. 소개문에 적은 정보 수집 설정을 실제 폼 설정과 일치시켜 주세요.

## 섹션 A — 응답 대상과 배경

### U1. 현재 학적 상태는 무엇인가요?

- 유형: 객관식, 필수
- 보기: 학부 1학년 / 학부 2학년 / 학부 3학년 / 학부 4학년 이상 / 현재 학부생이 아님
- 분기: 1~4학년 → 섹션 B, 현재 학부생이 아님 → 제출
- 섹션의 마지막 질문으로 배치

## 섹션 B — 연구실 선택 기준

**섹션 설명:** 연구실을 찾아본 경험이 있다면 가장 최근의 선택 당시를 기준으로 답해 주세요. 경험이 없다면 앞으로 선택할 때의 기준을 답해 주세요.

### U2. 포항공과대학교에서 현재 주전공은 무엇인가요?

- 유형: 객관식, 필수
- 보기: 수학과 / 물리학과 / 화학과 / 생명과학과 / 신소재공학과 / 기계공학과 / 산업경영공학과 / 전자전기공학과 / 컴퓨터공학과 / 화학공학과 / 의공학과 / 반도체공학과

### U3. 연구실을 선택할 때 얼마나 중요한가요?

- 유형: 항목별 개별 선형 배율 1~5점, 모두 필수. 모바일에서 제목을 읽을 수 있도록 그리드를 사용하지 않음
- 설명: 각 항목을 1~5점으로 평가해 주세요. 1 전혀 중요하지 않음 / 2 별로 중요하지 않음 / 3 보통 / 4 중요함 / 5 매우 중요함. 연구실을 선택한 경험이 있다면 당시 기준으로, 없다면 앞으로의 기준으로 답해 주세요.
- 각 질문 제목(U3-1~U3-7):
  1. 연구 주제가 내 관심사와 맞는 정도
  2. 배울 수 있는 연구 방법과 기술
  3. 실제로 맡게 될 업무와 역할
  4. 교수·대학원생의 지도와 피드백
  5. 연구실 분위기와 구성원 간 관계
  6. 참여 시간·기간과 학업을 병행할 수 있는 정도
  7. 진학·취업에 도움이 되는 경험
- 양 끝 표시: ‘전혀 중요하지 않음’, ‘매우 중요함’

### U4. 관심 연구 주제가 비슷한 연구실 두 곳 중 하나를 선택한다면, 최종 선택을 가장 크게 좌우할 기준은 무엇인가요? 최대 2개를 선택해 주세요.

- 유형: 체크박스, 필수, 응답 확인으로 최대 2개
- 보기:
  - 더 체계적인 지도와 피드백
  - 나에게 잘 맞는 분위기와 구성원 관계
  - 더 명확한 업무·역할과 성장 기회
  - 더 유연한 참여 시간·기간
  - 더 좋은 연구 성과·평판과 진로 기회
  - 더 좋은 보수·연구 지원 조건
  - 위 항목 외의 기준

### U5. 연구실을 찾거나 비교할 때 주로 이용한 정보원은 무엇인가요? 최대 2개를 선택해 주세요.

- 유형: 체크박스, 필수, 최대 2개
- 보기:
  - 연구실 홈페이지·논문·프로젝트 소개
  - 교수와의 직접 상담
  - 해당 연구실 대학원생과의 대화
  - 연구참여 경험이 있는 학부생·선배와의 대화
  - 연구실을 찾아본 적이 없음
- 설명: ‘찾아본 적이 없음’은 단독으로 선택해 주세요.

U6은 삭제했습니다. 나머지 분석용 문항 ID는 유지합니다.

## 섹션 C — 실제 연구참여 경험

**섹션 설명:** 여러 연구실에서 참여했다면 가장 최근에 참여한 한 곳을 기준으로 답해 주세요. 현재 참여 중이라면 지금까지의 경험을 기준으로 답해 주세요.

### U7. 해당 연구실에서의 연구참여 경험에 전반적으로 얼마나 만족하나요?

- 유형: 객관식, 필수
- 보기: 1 매우 불만족 / 2 불만족 / 3 보통 / 4 만족 / 5 매우 만족 / 연구참여 경험이 없음
- 설명: 연구참여 경험이 없다면 ‘연구참여 경험이 없음’을 선택해 주세요.
- 분기: 만족도 1~5점 → 섹션 C-2, 연구참여 경험이 없음 → 섹션 D
- 섹션의 마지막 질문으로 배치

## 섹션 C-2 — 연구참여 만족 요인과 기대

**섹션 설명:** 가장 최근에 참여한 한 연구실을 기준으로 답해 주세요.

### U8. 만족하거나 불만족하게 된 데 가장 큰 영향을 준 요인은 무엇인가요? 최대 2개를 선택해 주세요.

- 유형: 체크박스, 필수, 최대 2개
- 보기:
  - 연구 주제와 내 관심사의 일치 정도
  - 지도·피드백의 질과 빈도
  - 연구실 분위기와 구성원 관계
  - 업무량·참여 시간과 학업 병행
  - 보수·연구 지원 조건
  - 진학·취업에 도움이 된 정도
  - 위 항목 외의 요인

### U9. 참여 전에 기대했던 내용과 실제 경험은 얼마나 일치했나요?

- 유형: 객관식, 필수
- 보기: 1 전혀 일치하지 않음 / 2 별로 일치하지 않음 / 3 보통 / 4 대체로 일치함 / 5 매우 일치함

**섹션 종료 후:** 섹션 D로 이동

## 섹션 D — 더 필요한 정보와 대화 수요

### U10. 연구실을 선택하기 전에 추가로 알 수 있다면 가장 도움이 될 정보는 무엇인가요? 최대 2개를 선택해 주세요.

- 유형: 체크박스, 필수, 최대 2개
- 보기:
  - 학부생이 실제로 맡는 업무와 하루 일과
  - 지도·피드백 방식과 질문하기 쉬운 정도
  - 연구실 분위기와 구성원 간 소통 방식
  - 주당 참여 시간·기간과 학업 병행 가능성
  - 필요한 사전 지식·기술과 선발 기준
  - 현재 진행 중인 연구 주제와 프로젝트
  - 보수·지원 조건과 진로 연결 기회
  - 추가 정보가 필요하지 않음
  - 위 항목 외의 정보
- 설명: 경험자는 당시 부족했던 정보를, 경험이 없는 분은 앞으로 필요한 정보를 선택해 주세요. ‘추가 정보가 필요하지 않음’은 단독 선택해 주세요.

### U11. 현재 확보한 정보만으로 나에게 맞는 연구실을 선택할 수 있다고 얼마나 확신하나요?

- 유형: 객관식, 필수
- 보기: 1 전혀 확신하지 못함 / 2 별로 확신하지 못함 / 3 보통 / 4 대체로 확신함 / 5 매우 확신함 / 판단할 정보가 없음
- 분석: 마지막 보기는 점수 계산에서 제외하고 별도 집계

**아래 설명을 U12 바로 앞에 표시:**
다음은 검토 중인 서비스입니다. 관심 연구실의 대학원생과 1:1로 연결되어, 온라인에서 20분 동안 연구실 생활과 학부생의 연구참여 경험에 관해 질문할 수 있습니다. 이 문항에서는 무료로 이용할 수 있다고 가정해 주세요.

### U12. 향후 연구실을 선택할 때 이 대화를 이용할 의향은 어느 정도인가요?

- 유형: 객관식, 필수
- 보기: 1 전혀 없음 / 2 별로 없음 / 3 보통 / 4 있음 / 5 매우 있음

### U13. 이러한 대화를 이용할 때 가장 큰 걸림돌은 무엇인가요?

- 유형: 객관식, 필수
- 보기:
  - 현재 연구참여 계획이나 정보 필요가 없음
  - 대화 상대의 정보가 솔직하고 정확할지 걱정됨
  - 대화 내용이 연구실에 전달되어 지원에 영향을 줄까 걱정됨
  - 질문을 준비하거나 처음 보는 사람과 대화하기 부담스러움
  - 시간·일정 조율이 어려움
  - 위 항목 외의 걸림돌
  - 특별한 걸림돌이 없음

**섹션 종료 후:** 제출

## 경로 요약

- 현재 학부생: A → B → C → 경험자만 C-2 → D → 제출
- 현재 학부생이 아닌 응답자: A → 제출, 본 분석에서 제외
- 경험자: 18개 응답 항목, 미경험자: 16개 응답 항목. U3은 7개의 개별 질문으로 표시됩니다.
- 모두 선택형이며 자유서술 문항은 없습니다.
