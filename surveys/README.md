# UGRP 커피챗 가설 검증 설문

두 문서는 Google Forms에 옮겨 입력할 수 있는 설계안입니다. 이 환경에서는 실제 Google Forms 생성 여부를 확인할 수 없습니다.

수동 입력 대신 [Google Forms 자동 생성 안내](GOOGLE_FORMS_SETUP.md)에 따라 [Apps Script](create-google-forms.gs)를 한 번 실행하면 두 폼과 응답 시트를 생성할 수 있습니다.

이미 초기 폼을 만들었다면 같은 프로젝트의 코드를 교체하고 `createUGRPSurveys`를 실행해 두 설문의 수정본과 새 응답 시트를 만드세요. 기존 폼과 응답은 보존됩니다. 학부생 수정본만 필요하면 `createUpdatedUndergraduateSurvey`를 실행합니다.

대학원생 기존 폼의 제목·소개·참여 조건·G1·G2·G5 및 기타 입력 칸을 수정하려면 최신 코드로 교체하고 `updateGraduateSurvey`를 실행하세요. 실행 로그에 수정한 폼 링크가 표시됩니다.

- [학부생 설문](undergraduate-google-form.md): 선택 기준, 유사 연구실 간 결정 요인, 경험 만족도, 만족 요인, 부족한 정보, 무료 커피챗 이용 의향
- [대학원생 설문](graduate-google-form.md): 참여 관심, 최소 금전 보상, 비금전 보상, 기대, 적정 시간, 공급 가능 횟수, 참여 장벽

## 설계 원칙

중요도·만족도·의향은 1~5점으로 측정합니다. 요인·금액·시간은 선택형으로 묻습니다. 금액과 거절 의사를 모두 5개의 보기에 압축하면 무보상 가능과 참여 불가를 구분하기 어려워 금액 문항은 7개 보기를 사용했습니다. 점수 문항도 필요한 경우 ‘판단할 정보가 없음’을 따로 둡니다. 이 보기는 3점으로 처리하지 않습니다.

학부생은 먼저 경험과 정보 수요를 답하고 마지막에 서비스 설명을 읽습니다. 만족도는 가장 최근의 한 연구실에 대한 평가로 통일하고 경험자에게만 묻습니다. 중요도 평가는 여러 항목이 모두 높게 나올 수 있으므로 최대 2개 선택 문항으로 우선순위도 확인합니다.

대학원생 보상 문항은 온라인 대화 20분, 질문은 적어도 하루 전 전달, 준비는 자율적으로 진행하는 조건입니다. 다른 시간에 대한 보상으로 해석하지 않습니다. 소개문의 소요 시간은 추정이며 배포 전 확인해야 합니다.

## Google Forms 설정 및 입력 순서

1. 빈 폼 두 개를 만들고 각 문서의 제목·소개문·제출 후 메시지를 입력합니다.
2. 설계안의 섹션을 순서대로 만들고 문항을 입력합니다. U/G 번호는 분석용 ID이므로 질문 제목에서는 생략해도 됩니다.
3. 이메일 수집을 끄고, 소속 조직 사용자 제한을 끕니다. 로그인 없이 응답받으려면 ‘응답 1회로 제한’도 끕니다. 이 경우 중복 응답을 완전히 막을 수는 없습니다.
4. 선택형 설문 문항은 필수로, 대학원생 기타 내용 입력 칸은 선택 응답으로 설정합니다. 분기로 건너뛴 섹션에는 응답할 필요가 없습니다.
5. 체크박스 문항은 ‘응답 확인 → 최대 선택 개수 → 2’로 설정합니다. 오류 메시지는 ‘최대 2개까지 선택해 주세요’로 입력합니다.
6. U3은 항목별 개별 선형 배율 질문 7개로 만들고 각각 1~5점·필수로 설정합니다. 그리드는 사용하지 않습니다.
7. U1, U7에 ‘답변을 기준으로 섹션 이동’을 설정합니다. 이 질문들은 해당 섹션의 마지막에 배치합니다. U7에서 경험이 없는 응답자는 D로, 1~5점 응답자는 C-2로 이동합니다. C-2 종료 후에는 D로 이동합니다. G1은 석사·박사·통합 세 보기이며 모두 B로 이동합니다.
8. 전체 질문 순서와 1~5점 보기 순서는 섞지 않습니다. 응답 결과 요약을 응답자에게 공개하지 않도록 설정합니다.
9. 각각 별도 응답 스프레드시트를 연결합니다. 연락처가 필요한 후속 참여 모집은 이 설문과 분리합니다.
10. 배포 전 현재 학부생 경험자·미경험자·비대상자와 대학원생의 경로를 미리보기로 확인합니다. 모바일에서 항목별 1~5점 질문의 가독성과 실제 응답 시간도 확인합니다. 대학원생 설문은 소개문에 명시한 재학 중이며 연구실에서 활동하는 분에게 배포합니다.

Google Forms는 객관식·드롭다운 질문에서 응답별 섹션 이동을 지원합니다. [Google 공식 분기 안내](https://support.google.com/docs/answer/141062?hl=ko)

체크박스 최대 선택 개수는 응답 확인 설정으로 지정할 수 있습니다. [Google 공식 응답 규칙 안내](https://support.google.com/docs/answer/3378864?hl=ko)

‘없음’과 다른 선택지의 동시 선택을 최대 개수 설정만으로 막을 수는 없습니다. 문항 설명에 단독 선택을 안내하고, 동시 선택된 해당 문항은 결측 처리한 뒤 건수를 보고하세요. 응답 전체를 자동으로 삭제하지는 마세요.

## 확인할 가설과 분석

| 확인할 가설 | 문항 | 분석 방법 |
|---|---|---|
| 연구 주제 외에도 지도·업무·분위기가 선택에 영향을 준다 | U3, U4 | 항목별 4~5점 비율과 최대 2개 선택률을 함께 비교 |
| 연구참여 전 정보와 실제 경험 사이에 차이가 있다 | U7, U9 | 경험자만 만족도 평균·중앙값·분포, 기대 일치 1~2점 비율 집계 |
| 부족한 정보는 대학원생과의 대화로 얻을 수 있는 내용이다 | U10 | 항목별 선택률을 경험 유무별로 비교 |
| 학부생이 해당 대화를 이용할 의향이 있다 | U11~U13 | 무료 이용 의향 4~5점 비율과 주요 장벽, 정보 확신도별 차이 집계 |
| 일정 보상에서 참여 가능한 대학원생이 존재한다 | G3, G4, G8 | 가격별 조건부 참여 가능 비율과 월 가능 횟수를 함께 확인 |
| 비금전적 보상으로 참여를 고려하는 집단이 있다 | G4~G6 | 금전 보상 요구 집단과 무보상 가능 집단별 G5 선택률 비교 |
| 운영 가능한 대화 시간과 공급 규모가 있다 | G7~G9 | 시간별 선택률, 월 가능 횟수 분포, 주요 장벽 집계 |

### 집계 규칙

- 모든 결과에 대상 응답자 수(n)를 표시합니다. 비대상자는 별도 집계하고 본 분석에서는 제외합니다.
- 복수선택 문항은 선택 수가 아니라 해당 문항의 유효 응답자 수를 분모로 계산합니다. 합계가 100%를 초과할 수 있습니다.
- U6은 삭제했습니다. U7의 ‘연구참여 경험이 없음’으로 경험 유무를 구분합니다. 탐색·지원 경험이나 참여 중·완료 여부는 수집하지 않으며 과거 선택 기준과 미래 예상 기준을 정확히 구분할 수 없습니다. U3의 7개 응답 열을 항목별로 분석합니다.
- U7의 ‘연구참여 경험이 없음’은 만족도 평균·중앙값·분포 계산에서 제외합니다.
- U7 평균은 ‘응답한 경험자의 최근 연구참여 만족도 평균’입니다. 전체 학부생의 평균이나 여러 연구실의 평균이 아닙니다. U8은 영향 요인의 자기보고이므로 만족도의 인과관계나 영향 방향을 증명하지 않습니다.
- G4에서 10,000원 조건부 참여 가능 비율은 0원·5,000원·10,000원 선택자 수 / 전체 대상자의 유효 G4 응답 수로 계산합니다. 다른 가격도 동일하게 누적 계산합니다. 참여 불가와 30,000원 초과 응답도 분모에 포함합니다.
- 30,000원 초과 보기는 금액을 알 수 없고 ‘참여 의향 없음’은 가격이 아닙니다. 전체 금액 평균을 계산하지 말고 가격별 비율을 보고하세요.
- G4는 제시 가격 선택에 영향을 받는 가상 응답입니다. 실제 공급량을 확정하지 않습니다. G8과 함께 보고, 후속 파일럿에서 예약·완료율로 확인합니다.
- 학부생 U12는 무료 이용 의향입니다. 학부생 유료 지불 의향이나 서비스 수익성을 검증한 것으로 해석하지 않습니다. 대학원생 보상이 필요할 경우 비용 부담 주체는 별도로 검증해야 합니다.
- 편의 표본의 비율을 전체 학생의 비율로 일반화하지 않습니다. 연구참여 경험자만 모집하지 말고 미경험자도 포함하고, 학년·분야·모집 경로별 구성을 기록합니다. 적은 집단의 차이는 탐색적으로만 해석합니다.
- 분석 전에 ‘이용 의향’, ‘해당 가격에서의 공급’, ‘월 공급 횟수’ 중 어떤 지표를 다음 실험의 기준으로 쓸지 팀에서 정합니다. 임의의 비율을 보편적 성공 기준으로 제시하지 않습니다.

## 배포 전 확인과 다음 단계

학부생과 대학원생을 각각 소수 모집해 휴대폰으로 시범 응답을 받습니다. 질문 해석이 다른 항목, 보기에서 빠진 항목, 소요 시간을 확인한 뒤 본 배포를 진행하세요. 대학원생의 기타 서술 응답을 검토하고 ‘위 항목 외’ 응답이 많으면 다음 설문에서 보기를 보완합니다.

설문 이후에는 주요 정보 수요와 가능한 보상 조건을 바탕으로 소규모 커피챗을 운영해 실제 신청률·예약률·완료율·대화 후 유용성을 확인합니다. 설문의 이용 의향을 실제 행동과 비교해야 매칭 기능의 수요를 판단할 수 있습니다.
