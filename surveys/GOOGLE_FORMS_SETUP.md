# Google 계정에서 설문 2개 자동 생성하기

이 저장소의 `create-google-forms.gs`는 학부생 수정본과 대학원생 선택형 9문항과 선택 서술형 4문항을 Google Forms로 생성합니다. 학부생 수정본은 U6을 삭제하고 U3을 7개 개별 질문으로 나누어 경험자 18개, 미경험자 16개 응답 항목으로 구성합니다.

## 이미 폼을 만든 경우: 두 설문 수정본 생성

**대학원생 기존 폼에 수정사항을 적용하려면:** 원래 폼을 생성한 Apps Script 프로젝트에서 `Code.gs` 전체를 최신 코드로 교체하고 **updateGraduateSurvey**를 실행하세요. 제목·소개문·커피챗 조건을 최신 문구로 바꾸고, G1 과정·G2 소속 목록·G5 보기를 수정합니다. G5에 연구실 홍보 보기를 넣고 G2·G5·G6·G9 바로 아래에 선택 응답인 기타 입력 칸을 추가합니다. 재실행 시 입력 칸을 중복 생성하지 않습니다. 기존 폼 링크와 응답 시트를 유지합니다. 이미 받은 응답은 이전 선택지 기준일 수 있습니다. 수정본(V2)이 있으면 그 폼을, 없으면 초기 폼을 수정합니다. 저장된 폼이 없으면 대학원생 폼을 생성합니다. 실행 로그의 `editUrl`로 수정 대상 폼을 확인하세요.

같은 Apps Script 프로젝트의 `Code.gs`를 수정된 스크립트 전체로 교체하고 저장한 뒤 **createUGRPSurveys**를 실행하세요. 두 설문의 수정본과 새 응답 시트를 생성하고 실행 로그에 링크를 표시합니다. 기존 폼과 응답은 보존됩니다. 수정본을 다시 실행하면 같은 링크를 반환합니다. 수정본은 미게시 상태이며 검토 후 새 링크로 공유하세요. 학부생 수정본만 필요하면 **createUpdatedUndergraduateSurvey**를 실행합니다.

수정 사항: POSTECH 12개 학과 선택지, U3 항목별 1~5점 질문, U5 학교 공지·설명회·온라인 커뮤니티 보기 삭제, U6 삭제, U8 실제 업무·역할과 배움의 기회 보기 삭제. 경험 유무 분기는 U7로 옮겼습니다.

대학원생 수정 사항: G1 석사·박사·통합 세 보기, G2 학과와 융합·특화 대학원 조직 선택지, G5 학부생의 질문·관심사 요약 리포트 및 서비스 내 유료 기능·자료 이용 혜택 삭제. G1의 비대상자 분기는 제거했으며 소개문에 명시한 대상자에게 배포합니다.

현재 대화에서는 Google 계정에 접근할 수 없어 실제 폼은 아직 생성하지 않았습니다. 아래 실행은 사용자의 Google 계정에서 진행해야 합니다.

## 실행 순서

1. [Google Apps Script](https://script.google.com/)에 폼을 소유할 계정으로 로그인하고 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs`의 내용을 지우고 [생성 스크립트](create-google-forms.gs)의 전체 코드를 붙여넣어 저장합니다.
3. 상단 함수 목록에서 **createUGRPSurveys**를 선택하고 **실행**을 누릅니다. ‘배포’ 버튼을 누르거나 API 키를 발급할 필요는 없습니다.
4. 처음 실행할 때는 Google의 권한 요청 화면에서 이 프로젝트의 **Google Forms·Sheets 접근 권한**을 승인합니다. 폼과 응답 시트를 만드는 데 필요한 권한입니다.
5. 실행이 끝나면 **실행 로그**에서 각 폼의 `editUrl`을 열어 검토합니다. `responseSheetUrl`은 응답 시트 링크입니다.
6. 학부생 경험자·미경험자·비대상자의 분기와 대학원생 전체 경로를 미리보기로 확인합니다. 소속 조직 제한 등 **응답자 접근 설정을 확인하고 게시**한 뒤 응답 링크를 배포합니다. 시크릿 창에서 링크를 열어 로그인 없이 응답 가능한지도 확인하세요.

## 자동으로 설정되는 항목

- 제목·설명·완료 메시지, 모든 질문과 보기
- 연구참여 경험 및 대상자에 따른 섹션 분기
- 선택형 질문 필수 응답, 체크박스 최대 2개 선택, 항목별 1~5점 중요도 질문
- 대학원생 G2·G5·G6·G9 기타 내용 입력 칸: 선택 응답이며 해당 보기를 선택한 경우에만 작성
- 이메일 미수집, 응답 1회 제한 해제, 질문 순서 고정, 결과 요약 비공개
- 폼별 별도 응답 스프레드시트
- 미게시 상태 생성: 검토 후 편집 화면에서 직접 게시

학내 Google Workspace 정책에 따른 외부 응답 허용 여부는 계정에 따라 달라질 수 있으므로 편집 화면에서 확인해야 합니다. ‘없음’과 다른 보기의 동시 선택은 설명으로 안내하며, 자동 배타 선택 검증은 적용하지 않습니다.

## 재실행과 오류

`createUGRPSurveys`와 `createUpdatedUndergraduateSurvey`는 같은 계정과 같은 Apps Script 프로젝트에서 성공한 작업을 재실행하면 이미 만든 폼의 링크를 반환합니다. 완료된 폼의 문항을 덮어쓰거나 설문·시트를 중복 생성하지 않습니다. 다른 프로젝트에 코드를 붙여넣어 실행하면 별도 폼이 만들어집니다.

생성 도중 실패하면 해당 폼의 ID가 저장되어 재실행 시 중복 생성을 막고 중단된 폼의 편집 링크를 알려줍니다. 실행 로그의 오류와 링크를 확인하세요. 실패한 실행은 모든 문항과 응답 시트가 만들어졌다는 뜻이 아닙니다. 실패 후 자동 재구성을 하지는 않습니다.

`updateGraduateSurvey`는 실행할 때마다 기존 대학원생 폼에 최신 수정사항을 적용합니다.
