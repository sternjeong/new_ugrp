# 최종 데이터셋 기반 추천 구조 검증

2026년 10월 15일 · 회의 자료 · 최종 입력: `final_courses.jsonl`, `final_labs.jsonl`

## 회의에서 결정할 것

1. **데이터 구조:** 원문 근거를 잃지 않는 과목·개설·교수·연구실·논문 수록 주장·개념 뜻·관계 주장 구조를 제품의 목표 계약으로 둘지.
2. **추천 규칙:** 연구 주제 검색과 준비 과목 연결을 분리하고, 직접 방법 교집합 규칙을 단독 추천 엔진으로 쓰지 않을지.
3. **검증 범위:** 이번 결과는 정보량 프록시를 충족한 교수 행과 두 Luna의 판정에 조건부다. 실제 학생 의사결정 검증과 서비스 가중치 결정은 별도 단계로 둘지.

## 1. 입력과 평가 단위

| 항목 | 수량 | 해석 |
|---|---:|---|
| 최종 원본 과목 / 교수별 연구실 행 | 1,316 / 365 | 파일을 그대로 보존 |
| 정보량 조건 충족 과목 / 교수 행 | 941 / 203 | 길이·대표 논문 초록 기준의 작동상 프록시 |
| 공유 근거 구성요소 | 156 | 같은 소개·URL·논문 등의 누수 방지 묶음 |
| 개발 / 보류 | 19구성요소·23행 / 137구성요소·180행 | 규칙 수정과 판정 분리 |
| 평가 추출 | 112구성요소·136행 | 보류 구성요소 단순무작위 추출 |

과목의 설명과 학습목표는 적격 941행에서 동일하므로 독립 근거 두 개로 세지 않았다. 연구실 소개에는 모집 안내가 섞이고, 적격 행도 대표 논문 근거량이 다르다. “정보량 충족”은 의미적 완전성의 보증이 아니다.

112개 구성요소는 **보류 137개 구성요소 안의 이항 비율 하나**에 대해 최악 분산과 유한모집단 보정으로 약 ±3.97%p 목표를 둔 크기다. 개발 19개를 합친 적격 156개 전체에 대한 보장은 아니다. 실제 짝차이, 희귀 거짓 연결, 학과별 차이, 두 심사위원 불일치가 같은 오차 안에 든다는 뜻은 아니다. 모든 추천 비교는 구성요소 단위로 불확실성을 계산했다.

## 2. 스키마 결정안

| 필수 레코드 | 저장할 핵심 정보 | 규칙에 필요한 이유 |
|---|---|---|
| `course` + `course_offering` | 정규 코드, 원본 개설, 설명·진도 | 비슷한 코드와 동일 내용을 섣불리 합치지 않음 |
| `advisor` + `lab` + `lab_membership` | 교수와 임시 연구실 ID, 출처상 소속 | 교수 행을 실제 하나의 연구실로 자동 병합하지 않음 |
| `paper` + `paper_lab_evidence` | DOI/OpenAlex 또는 출처별 임시 ID, 목록별 `claim_id` | 논문 수록과 현재 연구실 대표성을 구분 |
| `source_evidence` | 파일 SHA·원본 행·중첩 필드·정확한 문자 범위·원문 | 연결 근거를 원본까지 추적 |
| `concept_sense` + `sense_mapping` + `assertion` | 분야·문제·방법·도구 구분, 버전별 개념 뜻, `uses/develops/studies/teaches`, 검토 상태 | 같은 단어의 다른 뜻과 행동을 구분 |
| `lab_discovery_evidence` + `recommendation_evidence` | 발견 근거와 준비 과목 연결을 분리, 양쪽 주장 ID, 뜻 ID, 점수 상태, 보류 사유 | 논문 수록 주장·연구실 발견을 준비 과목 점수로 자동 승격하지 않음 |

직접 연결에 쓸 정보는 연구실 자신의 사용·개발 문장, 대표 논문 초록의 연구 행위, 과목 설명·진도의 가르치는 내용이다. 과목 제목은 검색 힌트로만 두고, 복사된 학습목표·논문 수·개설 횟수는 독립 증거로 중복 가산하지 않는다. BGE 상위 5개에서는 동일 제목·교육 본문 후보가 기본 순위 75/136행, 규칙 가산 순위 73/136행에서 두 칸 이상을 차지해 표시 중복 관리가 필요하다. 선수사항 문구와 사이트/교수 논문 목록은 검토 전 후보 주장으로 보존한다.

`staging-v2`에서는 논문 목록 수록 주장 37,417건과 원문 근거 48,645건의 고유 ID·외래 키·문자 span이 전부 원자료와 일치했다. 구조 결정안은 두 Luna가 검토·수용했다. 개념 뜻과 관계 주장, 결측 상태, 서비스 출력 레코드는 **목표 계약**이며 아직 완성된 앱 자료라고 주장하지 않는다. 원본 JSONL은 수정하지 않았다.

## 3. 실험별 판정

| 실험 | 두 Luna의 제한 결과 또는 진행 상태 | 제품 판단 |
|---|---|---|
| 직접 관계 B1 대 동일 확장 어휘 B0 | 910쌍 판정. B1은 136행 중 79행에서 빈 목록. 고정 5칸 효용 A 0.191 대 B0 0.612, B 0.213 대 0.623. 구성요소 짝차이의 두 95% 구간 모두 음수 | B1 단독 추천 채택 근거 없음 |
| Kaggle BGE 상위 1개 | 136행에서 규칙 0.08 가산이 첫 과목을 바꾼 행 37개. 효용·무관 비율 차이의 두 심사 구간 모두 0 포함 | 고정 가산값 채택 근거 없음 |
| Kaggle BGE 상위 5개 사후 확장 | 신규 562쌍씩 두 Luna 판정. 고정 5칸 효용의 규칙 가산−기본 차이 A +0.016 (95% 구간 −0.008~+0.040), B +0.003 (−0.015~+0.020). 무관 항목 비율 차이의 두 구간도 0 포함 | 탐색적 노출 비교만 수용; 고정 가산의 일관된 품질 개선은 입증되지 않음 |
| 질의 해석 Q0 대 Q1 | 작성 질의 60개 중 명시적 부정 30개: 관련 항목 비율 Q1−Q0 A +8.7%p, B +6.7%p. 위반 차이 구간은 둘 다 0 포함 | 부정 표현 분리의 가능성은 보이나 실제 사용자 안전성 확증은 아님 |
| 이유 문장 R0 대 R1 | 관련·근거 충분 B1 27쌍. R1의 충실도 향상은 두 심사에서 일치하지 않음 | 원문 인용만으로 사실성을 보증할 수 없음 |
| A/B 표시 방식 | 같은 27쌍에서 두 Luna는 R1을 A 20건/B 24건 선택. 근거 밖 주장 표시는 두 형식 동수 | 이 카드의 표시 선호일 뿐 학생 선택 효과 아님 |
| 피드백 관문 스트레스 | 합성 1개 제거 후 6위 유입의 무관 비율 A 25.5%, B 31.8%. 최초 5개 고정은 외부 유입 0, 목록 4개 | 빈 칸 재채움의 위험과 가변 길이 교환을 보여 줌 |

BGE 순위는 Kaggle T4 실행 `20261014-234632-bge-rich-kaggle`에서 BAAI/bge-m3 개정 `5617a9f61b028005a4858fdac845db406aefb181`, 최대 256토큰 청크, 정규화 cosine으로 생성했다. 0.08 규칙 가산은 동결 v15 직접 연결에만 적용했다. CPU에서는 모델 인코딩을 수행하지 않았다.

관계 평가의 두 Luna 관련도 완전 일치는 71.1%, BGE 상위 5개 신규 쌍은 58.2%(327/562, 0 대 2가 48쌍), 질의 쌍은 86.4%(59쌍 불일치, 그중 9쌍은 0 대 2), A/B 카드 선택은 66.7%였다. 두 모델 심사위원의 점수를 평균해 사람의 “정답”으로 만들지 않았다. BGE 상위 5개에서 B만 `무관 항목이 하나라도 있음` 지표가 개선된 구간(−5.9%p, 95% 구간 −11.2~−0.9%p)을 보였으나 A의 구간은 0을 포함했다. 질의 심사위원 둘 다 설계 검토 때 목표 파일을 봤다. 질의 결과는 방법·순위 블라인드였지만 목표 블라인드는 아니다.

## 4. 규칙 기반 서비스에 적용할 순서

1. 원자료 적격성·출처 품질을 기록하고 결측을 0점과 분리한다.
2. 사용자 관심의 좋아하는 주제, 명시적 싫은 주제, 모호성을 별도 구조로 저장한다. 분리 실패나 긍정 관심이 없으면 자동 검색을 보류한다.
3. 연구실 발견 후보는 넓게 검색한다. BGE-M3 같은 GPU 모델의 인코딩·재계산은 **Kaggle GPU에서만** 수행한다.
4. `studies`는 연구실 발견에 쓰고 준비 과목 점수로 바로 승격하지 않는다. `uses/develops` 방법·도구와 과목의 `teaches`가 **같은 개념 뜻**일 때 직접 연결 후보로 둔다.
5. 원문 문맥·행동 주체·대상 객체로 `logic`이나 `manipulation` 같은 다의어를 판별한다. 불명확하면 보류한다. 규칙이 빈 목록을 만들면 규칙 단독 결과를 제품 추천 목록으로 대체하지 않는다.
6. 연결 설명은 출처 span과 검토 상태를 보여 준다. 근거가 빈약한 과목 제목만으로 준비 기술이나 선수 관계를 단정하지 않는다.
7. 피드백으로 노출 자격 집합을 자동 넓히지 않는다. 자격 밖 후보는 별도 검토·탐색 경로에서 다룬다. 현재 응답 효과나 승격 문턱은 검증되지 않았다.

**규칙 오류 예시.** 보류 판정의 `pair:000e492ab20d978a`는 논문 작성의 *logic*과 회로 논리를, `pair:013ddd2a0645d5cc`는 테라헤르츠파 *manipulation*과 로봇 조작을 같은 단어로 연결했다. 두 Luna 모두 두 쌍을 준비 과목 관련도 0으로 판정했다. 이 사후 오류 진단은 새 뜻 분리 규칙의 필요성을 보여 주지만 같은 보류 자료에서 재조정한 성능의 증거가 아니다.

## 5. 남은 검증과 결정 보류

- 적격하지 않은 과목 375행·교수 행 162행에는 이 수치를 일반화할 수 없다. 원문 갱신·의미 품질 검토 후 별도 평가한다.
- BGE 상위 5개 확장은 상위 1개 결과 뒤 정한 사후 분석이다. 두 Luna는 제한된 기술 결과로만 수용했다. 원래 `bge_m3`의 재순위·컷오프·전체 회수율은 이번 비교로 증명되지 않는다.
- 실제 학생의 관심 질의, 선택·납득도, 피드백 응답 확률과 연구실 간 전이는 아직 측정되지 않았다.
- `concept_sense`와 검토된 `assertion`을 구현하고 새 개발/보류 자료에서 규칙 가중치와 다의어 차단을 검증한 뒤 앱 정책으로 채택해야 한다.
