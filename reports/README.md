# reports

회의·실험 보고서의 원본(Markdown·HTML)과 PDF 빌드 스크립트를 둔다. PDF는 디스크 정리를 위해 2026-11-08에 저장소에서 뺐다.
- 필요하면 `build_pdf.py`, `build_meeting_pdf.py`, `build_embedding_rule_schema_lecture.sh`로 다시 만든다.
- 예전 PDF는 git 기록에서 꺼낼 수 있다(예: `git show 9444cff:reports/final_dataset_meeting_2026-10-15.pdf > out.pdf`).
- `docs/reports/`의 엔진 실험 보고서는 `docs/reports/src/`의 HTML이 원본이다.
