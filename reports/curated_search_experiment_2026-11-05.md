# 새 정제본 검색 엔진 진단 실험 (2026-11-05)

## 결론

현행 서비스의 **워커 부재 시 사전 검색 경로**를 새 정제본(연구실 307곳, 과목 1,151개)으로 실행했다. 작성자가 만든 20개 진단 질의에서 의도 분류는 15/20, 명시적 부정 주제 추출은 6/7이었다. 검색 목적이 아닌 질문 3개에 연구실 목록이 출력됐다. 이는 경로별 결함을 찾는 진단 결과이지 연구실 추천 정확도나 사용자 만족도 추정치가 아니다.

## 재현 방법과 범위

```bash
PYTHONPATH=. python3 experiments/curated_search_diagnostic.py > reports/curated_search_diagnostic_2026-11-05.json
PYTHONPATH=. python3 -m unittest tests.test_curated_catalog tests.test_query_engine tests.test_embed_worker -q
```

입력은 `data/sunwoo/`의 현행 `app_profiles.jsonl`, `courses.jsonl`이다. 진단 스크립트는 `CuratedQueryEngine`을 워커 없이 생성해 실제 오프라인 대체 경로를 호출한다. 상세 결과와 상위 3개 연구실 ID는 JSON에 기록했다. 관련 테스트 18개는 통과했다. 테스트 중 과거 4개 학과용 기록 유사도를 재현하는 테스트도 포함되므로, **테스트 통과를 새 정제본의 추천 품질 검증으로 해석하지 않는다**.

실험 시 공개 `/api/engine`은 `{"embedding":false}`였다. Kaggle BGE-M3 검색, dense/sparse 비교, 재순위화, 실제 지연 시간은 이 실험에서 실행하거나 측정하지 않았다. 기존 39개 개발 질의와 90개 시험 질의의 정답은 옛 4개 학과 프로필 개념에 묶여 있어 새 307개 연구실의 정답지로 사용하지 않았다.

## 관측 결과

| 항목 | 결과 | 해석 |
|---|---:|---|
| 의도 분류 | 15/20 | 작성자 제작 진단 사례 통과율. 일반화 불가 |
| 명시적 부정 주제 추출 | 6/7 | `좋아하지 않지만` 사례에서 `로봇` 누락 |
| 검색 외 질문에 연구실 목록 출력 | 3/8 | 수강신청, 대학원 지원, 교수에게 메일 쓰는 방법 |
| 코드·워커 프로토콜 관련 테스트 | 18/18 통과 | 기능 회귀 확인. 추천 관련도 판정은 아님 |

실패 사례:

- `수강신청은 어떻게 하나요` → `search`, 연구실 4곳. `대학원 지원 방법을 알려줘` → `search`, 10곳. `교수님께 메일을 어떻게 쓰나요` → `search`, 4곳. 현행 `CuratedQueryEngine.search`는 일반 `QueryEngine`의 진로/절차 의도 분기 대신 일부만 재사용한다.
- `asdf` → `search`로 판정하지만 결과 0곳. `ㅋㅋㅋㅋ` → `need_likes`. 무의미 입력의 사용자 메시지가 일관되지 않다.
- `로봇을 좋아하지 않지만 뇌 신호 분석은 좋아요` → 검색은 실행되지만 `로봇`을 부정 주제로 추출하지 못했다.

## 이 결과로 판단할 수 없는 것

연구실 추천의 precision, recall, nDCG@5, 근거 충실도, 과목 연결의 적합도는 **측정하지 못했다**. 이 지표에는 새 정제본을 기준으로 질의-연구실/과목 쌍을 독립 평가한 판정표가 필요하다. 이 20개 질문은 연구자가 코드를 본 뒤 작성했고 유형별 대표 표본도 아니다. 15/20을 전체 사용자 질의의 75% 정확도로 표현하면 안 된다.

## 다음 실험의 결정 기준

1. 학생이 작성한 새 질의 150~300개를 확보하고 유형별로 층화한다. 개발용과 잠금 시험용을 분리한다.
2. 현재 사전 검색, 현재 BGE-M3 결합, 후보 근거 검사, 대안 검색을 모두 실행해 상위 후보를 합친다. 출처와 모델명을 숨긴 채 연구실 관련도(0~3)와 근거 충실도(참/불명/거짓)를 독립적으로 판정한다. 평가자 불일치는 보존한다.
3. 주 지표를 연구실 nDCG@5로 사전 고정하고, 부정 의도 위반률·검색 외 질의 오출력률·근거 없는 설명 비율·P95 지연·임베딩 성공률을 함께 보고한다. 과목은 별도 판정표로 평가한다.
4. 모델·융합 가중치·문턱은 개발용에서만 조정하고 잠금 시험용에서는 한 번 평가한다. 개선 폭의 신뢰구간과 질의 유형별 악화를 함께 기록한다.

현재 자료에서 우선 고칠 대상은 **검색 외 의도 분기와 부정 표현 추출**이다. 관련도 판정표가 생기기 전에는 BGE-M3 결합 방식의 품질 향상을 주장하지 않는다.

## 후속 수정과 재측정

같은 날 `CuratedQueryEngine` 앞단에 의도 판정을 분리하고, 검색 외 질문은 워커 실행 전 종료하도록 수정했다. `좋아하지 않지만`을 명시적 부정으로 해석하며, 부정 표현의 대상을 추출하지 못하면 재입력을 요청한다. 사전 검색과 임베딩 순위 융합 뒤에는 **연구실 주제 라벨에 부정 구절이 명시적으로 겹치는 후보**를 제거한다. 의미상 숨은 충돌까지 탐지한다는 뜻은 아니다.

동일 20개 사례 재실행 결과는 의도 20/20, 부정 추출 7/7, 검색 외 질문의 연구실 출력 0/8이다. 후속 결과 원본은 `reports/curated_search_diagnostic_after_2026-11-05.json`에 있다. 관련 테스트 21개가 통과했다. 이 사례들은 수정 대상을 확인하는 회귀 진단셋이므로 **새 데이터에서의 일반화된 정확도 상승으로 해석하지 않는다**.
