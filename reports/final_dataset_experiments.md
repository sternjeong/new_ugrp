`final_courses.jsonl` 1,316행과 `final_labs.jsonl` 365행에서 근거를 추적할 수 있는 연구실·과목 연결 규칙을 만들고, 기존 실험을 같은 질문으로 재실행한다. 현재 **출처 정규화**와 **기존 개념 어휘의 문자열 후보 감사** 두 단계가 각기 제한된 목적에 대해 두 Luna 심사위원의 검토를 통과했다. 의미적 그래프 연결과 추천 성능은 아직 검증되지 않았다.

| 단계 | 재현 명령 | 두 심사위원의 판정 | 증명 범위 |

## 1. 출처 정규화: 수용

과목 코드 1,316개는 현재 파일에서 모두 고유했다. 연구실 행의 `advisor_id`는 365개 모두 고유하지만 각 행을 독립된 실제 연구실이라고 단정하지 않았다. 임시 `lab_id`는 교수별로 하나를 두고, `lab_group`이 반복되는 세 쌍도 자동 병합하지 않았다. 논문은 DOI 또는 OpenAlex ID가 있을 때만 식별 병합하고, 제목만 비슷한 항목은 검토 대상으로 남겼다.

| 생성 레코드 | 수량 |
|---|---:|
| 과목 / 개설 | 1,316 / 1,316 |
| 임시 연구실 / 교수 / 출처상 연결 | 365 / 365 / 365 |
| 논문 식별 레코드 / 논문·연구실 수록 주장 | 37,323 / 37,417 |
| 텍스트 근거 | 8,957 |

검증기는 8,957개 근거 조각의 원문 위치, 37,417개 논문 수록 주장의 원본 목록 위치, 37,323개 논문 식별 레코드의 출처, 모든 생성 레코드의 파일 해시·행 번호·스키마 버전과 참조 ID를 확인했다. `paper_lab_evidence`는 논문이 목록에 실렸다는 기록이며 연구실의 현재 주제와 관련 있다는 판정은 아니다. 초록이 없는 논문은 `title_only`로 표시한다.

독립 심사 A는 논문 목록 항목 대조 누락을, 심사 B는 여러 필드로 구성한 엔터티에 단일 `source_field`를 붙인 과장과 해시 검증 누락을 지적했다. 논문 항목 대조를 추가하고 엔터티 출처를 `$row`로 명시한 뒤 재검증했다. 최종 검증 결과 `valid: true`였다.

## 2. 기존 개념 어휘 문자열 감사: 제한적 수용

이전 앱의 70개 `concepts.json`에서 `keywords`만 사용했다. 넓은 사용자 표현용 `query_keywords`는 제외했다. 영어는 단어 경계를 확인하고 한국어는 부분 문자열로 검사했다. 숫자는 행 단위로 “키워드가 하나 이상 발견됨”을 센 것이다.

| 검사 범위 | 명중 행 / 전체 | 해석 |
|---|---:|---|
| 연구실 주요 필드: 키워드·소개·대표 논문 | 312 / 365 | 주요 출처의 문자 후보 |
| 연구실 모든 검사 필드: 사이트·교수 논문도 포함 | 326 / 365 | 논문 목록의 부수 언급까지 포함 |
| 과목 제목·설명·목표·진도 | 923 / 1,316 | 수업 내용의 문자 후보 |

연구실 필드별 명중 행: 자체 키워드 181, 소개 239, 사이트 논문 제목 185·초록 23, 교수 논문 제목 271·초록 14, 대표 논문 제목 244·초록 262. 한 행이 여러 필드에 나타나므로 합산하지 않는다.

두 심사위원은 처음 감사에서 사이트·교수 논문 목록이 빠졌다는 점을 지적했다. 출처군별 집계를 추가했다. 두 심사 모두 이 감사를 **의미적 관련성이나 그래프 연결의 정확도 평가로 사용하는 것은 기각**했다. 일반 단어·한국어 부분 일치는 거짓 양성일 수 있고, 미명중은 자료 결측 또는 어휘 누락일 수 있다. `method`/`domain`은 사전의 개념 종류이지 연구실이 실제 사용·연구한다는 관계가 아니다.

## 후속 판정 기준

다음 통과 대상은 문단·논문과 강의계획에서 `studies`·`uses`·`teaches`를 근거와 함께 만드는 규칙이다. 사람이 검토할 독립 표본에서 거짓 연결과 누락을 확인한다. 이후 기존 `bge_m3`, `query_understanding`, `reason_engine`, `ab_test`, `feedback_gate`의 질문·기준선·지표를 최종 후보 집합에 맞춰 재실행하고, 각 결과를 두 Luna 심사위원에게 방법명을 가린 상태로 판정받는다. 기존 작은 데이터셋의 수치를 이번 수치와 직접 비교하지 않는다.

관계 실험의 사전 등록안은 두 심사위원의 기각 사유를 반영해 수정했고, **공통 주요 필드의 파일럿 실행 계획으로 수용**됐다. 공유 사이트·소개·대표 논문을 기준으로 280개 구성요소를 만들어 시험 60개(교수 행 78)와 개발 30개(40)를 고정했다. 공유 근거 키 7,671개의 분할 교차는 0건이었다. 이 수용은 아직 관계 규칙 성능 판정이 아니다.

현재 이 PDF에 실린 “수용”은 두 기반 단계의 좁은 검증 범위에 한정된다. 추천 규칙이 완성되거나 과거 실험 결론이 재현됐다는 주장은 아직 할 수 없다.
